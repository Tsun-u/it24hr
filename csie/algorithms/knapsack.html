0/1 Knapsack　背包問題

生活應用

出國玩回來，行李還剩 7 公斤的額度。免稅店裡有五樣東西你都想買，重量不一樣，想要的程度也不一樣。要先拿最想要的、最輕的，還是每公斤最划算的？

複習

五樣東西 5、4、3、2、1 公斤，想要的程度是 10、7、6、2、1 分。先拿最想要的，拿到 12 分；先拿最輕的，9 分；先拿每公斤最划算的（5 公斤和 3 公斤那兩樣一樣划算，先拿比較想要的 5 公斤），12 分。可是 4 公斤和 3 公斤那兩樣一起拿有 13 分，三種挑法都沒挑到。 → 貪婪法

回溯每樣選或不選全部試過一定對，可是 30 樣就超過十億種。 → 回溯

一樣一樣考慮：這樣東西帶或不帶，兩邊各自最多幾分，挑大的那個記進表裡。

核心觀念

0/1 背包問題（0/1 knapsack problem）：有 n 樣東西，各有重量和價值，背包有重量上限；每樣只能拿或不拿，不能切開、不能拿兩次，要讓拿到的總價值最大。

表的每一格是一個小問題的答案：best[i][w] 是「只考慮前 i 樣東西、額度是 w 公斤」時最多幾分。 → 動態規劃

每一格只有兩個選擇。不帶第 i 樣：答案跟只有前 i − 1 樣一樣，是 best[i − 1][w]。帶第 i 樣（額度要裝得下它）：先扣掉它的重量，剩下的額度讓前 i − 1 樣去裝，再加上它的分數，是 best[i − 1][w − 它的重量] + 它的分數。兩個取大的。

第 0 列是一樣都還沒考慮，全部是 0。一列一列往下填，答案在最右下角。

每一列只看上一列，所以可以只留一列。這時候 w 要從大的填到小的：從小的開始填，後面的格子會用到這一輪剛改過的格子，等於同一樣東西拿了兩次。

什麼時候會用到

  • 行李限重、搬家時一台貨車裝哪些東西。
  • 預算有限，挑哪幾個計畫做：每個計畫要花多少、效益多少，總花費不能超過預算。
  • 「湊不湊得出某個金額」「用最少的硬幣找零」是它的親戚，一樣是一樣一樣考慮、把每個金額的答案記在表上。 → 動態規劃
  • APCS 實作題：每樣只能拿一次的 0/1 背包，和每樣可以拿很多次的無限背包。

常見誤解

誤解：先拿每公斤最划算的，就會最多分

正解：東西不能切，照這樣拿可能留下塞不滿的額度。開場那五樣，每公斤最划算的是 5 公斤和 3 公斤那兩樣，拿了 5 公斤的就裝不下 3 公斤的，最後只有 12 分；4 公斤加 3 公斤才是 13 分。 → 貪婪法

誤解：只留一列的寫法，w 從小到大填也一樣

正解：會把同一樣東西拿很多次，算出來的是「每樣可以拿很多次」的答案。每樣只能拿一次，w 要從大到小（試試看第二題）。

誤解：右下角只有分數，查不出拿了哪幾樣

正解：從右下角往回看：這一格跟正上方一樣，就是沒拿這一樣，往上一列；不一樣就是拿了，往上一列、再往左挪它的重量。

誤解：東西不多的話，表一定填得完

正解：表有幾格還要看額度多大：n 樣東西、額度 W，大約要填 n × W 格。額度是十億就填不完；這時候東西如果只有二十幾樣，反而用回溯。 → 回溯

實作

C

#include <stdio.h>

// 每樣東西只能拿一次，額度 limit 公斤，回傳最多幾分；best[i][w]：只考慮前 i 樣、額度 w 公斤時最多幾分
int max_value(const int weight[], const int value[], int n, int limit) {
    int best[n + 1][limit + 1];
    for (int w = 0; w <= limit; w++) best[0][w] = 0;   // 第 0 列：一樣都還沒考慮，全部是 0
    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= limit; w++) {
            best[i][w] = best[i - 1][w];               // 不帶第 i 樣
            if (w >= weight[i - 1]) {                  // 裝得下才能帶（第 i 樣放在陣列的第 i - 1 格）
                int take = best[i - 1][w - weight[i - 1]] + value[i - 1];
                if (take > best[i][w]) best[i][w] = take;
            }
        }
    }
    return best[n][limit];
}

int main(void) {
    int weight[] = {5, 4, 3, 2, 1};
    int value[] = {10, 7, 6, 2, 1};
    printf("%d %d\n", max_value(weight, value, 5, 7), max_value(weight, value, 5, 10));
    return 0;
}

def max_value(weight, value, limit):   # 每樣東西只能拿一次，額度 limit 公斤，回傳最多幾分
    n = len(weight)
    best = [[0] * (limit + 1) for _ in range(n + 1)]   # best[i][w]：只考慮前 i 樣、額度 w 公斤時最多幾分；第 0 列全部是 0
    for i in range(1, n + 1):
        for w in range(limit + 1):
            best[i][w] = best[i - 1][w]                # 不帶第 i 樣
            if w >= weight[i - 1]:                     # 裝得下才能帶（第 i 樣放在串列的第 i - 1 格）
                take = best[i - 1][w - weight[i - 1]] + value[i - 1]
                if take > best[i][w]:
                    best[i][w] = take
    return best[n][limit]

跑幾步

回溯每樣選或不選O(2ⁿ)
填表n × (W + 1) 格，每格看兩格，O(n × W)
只留一列時間一樣，空間從 n × W 變成 W

開場是 5 × 8 = 40 格對 32 種挑法，看不出差別；30 樣東西、額度 100 公斤是三千格對十億種。Big-O 的意思和怎麼算，在資料結構的附錄。 → 時間複雜度

試試看

程式運行追蹤1. 三樣東西重 2、3、4 公斤，分數是 4、5、6 分，每樣只能拿一次，額度 7 公斤。下面這段程式印出什麼？

C

int weight[] = {2, 3, 4};
int value[] = {4, 5, 6};
int best[] = {0, 0, 0, 0, 0, 0, 0, 0};
for (int i = 0; i < 3; i++) {
    for (int w = 7; w >= weight[i]; w--) {
        int take = best[w - weight[i]] + value[i];
        if (take > best[w]) {
            best[w] = take;
        }
    }
}
printf("%d\n", best[7]);
  1. 9
  2. 11
  3. 13
  4. 15

程式測試與除錯2. 三樣東西重 1、3、4 公斤，分數是 2、5、7 分，每樣只能拿一次，額度 5 公斤。最多應該是 9 分（1 公斤和 4 公斤那兩樣），這段程式卻印出 10。要怎麼改？

C

int weight[] = {1, 3, 4};
int value[] = {2, 5, 7};
int best[] = {0, 0, 0, 0, 0, 0};
for (int i = 0; i < 3; i++) {
    for (int w = weight[i]; w <= 5; w++) {
        int take = best[w - weight[i]] + value[i];
        if (take > best[w]) {
            best[w] = take;
        }
    }
}
printf("%d\n", best[5]);
  1. 把 take > best[w] 改成 take >= best[w]
  2. 把 w 改成從 5 往下跑到 weight[i]，從大的填到小的
  3. 把 i 改成從 2 往下跑到 0，三樣東西倒過來考慮
  4. 把 take 改成 best[w] + value[i]

程式效能分析3. 下面這段程式用二維的表算 6 樣東西、額度 9 公斤的背包，每填一格 cells 就加 1。它印出多少？

C

int weight[] = {3, 1, 4, 2, 5, 2};
int value[] = {4, 1, 6, 2, 7, 3};
int best[7][10] = {0};
int cells = 0;
for (int i = 1; i <= 6; i++) {
    for (int w = 0; w <= 9; w++) {
        best[i][w] = best[i - 1][w];
        if (w >= weight[i - 1]) {
            int take = best[i - 1][w - weight[i - 1]] + value[i - 1];
            if (take > best[i][w]) {
                best[i][w] = take;
            }
        }
        cells += 1;
    }
}
printf("%d\n", cells);
  1. 54
  2. 60
  3. 64
  4. 70

總結

三種直覺都差一點：最好的是 4 公斤和 3 公斤那兩樣，13 分。不用把 32 種挑法全部試過，一張 40 格的表填完就知道。下次碰到「每樣東西只能拿一次、總量有上限、要拿到最多」，你就知道：這是背包問題，照動態規劃填表。

課外補充

每樣可以拿很多次的無限背包：一樣的表，只留一列的寫法把 w 改成從小到大填，剛好就是它。同一個「錯誤」在另一題是正解。
