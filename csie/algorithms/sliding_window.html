Sliding Window　滑動視窗

生活應用

夜市一條路上有 12 攤你都想吃。你打算從某一攤開始，一攤接一攤吃過去，不跳攤。口袋裡有 300 元，最多可以連吃幾攤？

複習

雙指標那一頁，兩根手指從兩頭往中間收。這次兩根手指從同一頭出發、往同一個方向走。 → 雙指標

用兩層迴圈把每一段都加一遍，12 攤有 78 段；可是起點往右挪一攤的時候，中間那幾攤剛剛才加過。

右邊多吃一攤就加進來，超過預算就從左邊退掉一攤；總和跟著加加減減，不用重算。

核心觀念

滑動視窗（sliding window）是雙指標的一種：left、right 都從最左邊出發，中間夾的那一段叫視窗。right 一格一格往右，把新的一攤加進總和；總和超過預算，left 就往右，把離開的那一攤減掉，一直退到不超過為止。 → 雙指標

每一步做完，視窗是「吃到 right 這一攤為止、吃得起的最長一段」。把每一步的長度記下最大的，就是答案。

left 為什麼不用往回走：right 往右一攤之後，起點如果比現在的 left 還早，那一段會把剛才已經超過預算的那一段包在裡面，只會更貴。所以 left 只會往右。兩根手指各走一趟，最多 2n 步。

前提是價錢都不是負的：多吃一攤總和不會變少，少吃一攤不會變多，「超過就從左邊退」才成立。

視窗也可以固定寬度（最近 7 天）：每往右一格，右邊進一個、左邊出一個。

什麼時候會用到

  • 最近 7 天的平均步數、股票的均線：視窗固定 7 格寬，每過一天，加進新的一天、減掉最舊的一天。
  • 網站限制「一分鐘內最多 100 次請求」：只看最近一分鐘這個視窗裡有幾次，舊的請求從左邊滑出去。
  • 一串字裡最長的一段、裡面沒有重複的字元：右邊進來的字跟視窗裡的重複了，左邊就一直退到不重複為止。
  • APCS 實作題：連續一段的總和不超過 k 的最長長度、總和至少 k 的最短長度。

常見誤解

誤解：超過預算的時候，left 退一攤就夠了

正解：新進來的那一攤可能很貴，退一攤不一定回到預算內。要用 while 一直退到不超過為止，寫成 if 會留下超過預算的視窗（試試看第二題）。

誤解：for 裡面還有一個 while，所以是 O(n²)

正解：left 從頭到尾只往右走，全部加起來最多走 n 步，不是每一圈都從頭走。兩根手指合起來最多 2n 步，是 O(n)。

誤解：視窗的長度是 right − left

正解：兩頭都算在裡面，是 right − left + 1。

誤解：有負數也照樣能用

正解：夜市裡如果有一攤是「折 50 元」，超過預算之後再往右吃到那一攤，可能又回到預算內；這時候從左邊退就會錯過答案。

實作

C

#include <stdio.h>

// 連續吃、總和不超過 budget，最多可以吃幾攤；價錢都不能是負的
int longest_run(const int prices[], int n, int budget) {
    int left = 0, total = 0, best = 0;
    for (int right = 0; right < n; right++) {
        total += prices[right];          // 右邊多吃一攤
        while (total > budget) {         // 超過預算：從左邊一攤一攤退，退到不超過為止
            total -= prices[left];
            left++;
        }
        if (right - left + 1 > best) {   // 視窗兩頭都算，長度是 right - left + 1
            best = right - left + 1;
        }
    }
    return best;
}

int main(void) {
    int prices[] = {60, 90, 50, 120, 40, 70, 80, 100, 30, 110, 50, 60};
    printf("%d %d\n", longest_run(prices, 12, 300), longest_run(prices, 12, 200));
    return 0;
}

跑幾步

兩層迴圈把每一段都加一遍n(n + 1) / 2 段，至少 O(n²)
滑動視窗：right 走 n 步、left 最多走 n 步O(n)

12 攤 78 段對 24 步以內；一萬攤是五千萬段對兩萬步。Big-O 的意思和怎麼算，在資料結構的附錄。 → 時間複雜度

程式運行追蹤1. 另一條夜市有 6 攤，預算 150 元，一樣要一攤接一攤吃。下面這段程式印出什麼？

int left = 0, total = 0, best = 0;
for (int right = 0; right < 6; right++) {
    total += prices[right];
    while (total > 150) {
        total -= prices[left];
        left += 1;
    }

程式測試與除錯2. 5 攤、預算 150 元。這段程式想印出走完之後視窗裡還有幾攤、一共多少錢，結果印出 2 160：160 元超過預算了。要怎麼改？

C

int prices[] = {60, 90, 50, 120, 40};
int budget = 150;
int left = 0, total = 0;
for (int right = 0; right < 5; right++) {
    total += prices[right];
    if (total > budget) {
        total -= prices[left];
        left += 1;
    }
}
printf("%d %d\n", 5 - left, total);
  1. 把 total > budget 改成 total >= budget
  2. 把 if 改成 while，一直退到不超過為止
  3. 把 left += 1 改成 left += 2
  4. 把 total -= prices[left] 和 left += 1 這兩行對調

總結

最多 4 攤，例如第 2 攤到第 5 攤，90 + 50 + 120 + 40 剛好 300 元。不用把 78 段都加一遍，兩根手指各從頭走到尾一次就知道。下次碰到「連續的一段，最長或最短是多少」，你就知道：用一個視窗框住它，右邊進、左邊出。

課外補充

反過來問「最短的一段」：連續幾攤加起來至少 300 元，最少要幾攤。right 一樣往右加；總和夠了，就記下長度、從左邊退一攤再看還夠不夠。
