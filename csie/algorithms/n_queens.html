N-Queens　八皇后

生活應用

西洋棋的皇后可以橫著、直著、斜著走，走幾格都行。8 × 8 的棋盤上要放 8 個皇后，誰也吃不到誰。放得下嗎？

複習

回溯是走一步檢查一步，不行就退回上一步。64 格裡挑 8 格有 44 億種挑法，全部列出來再檢查，等不到答案。 → 回溯

先注意到一件事：同一列放兩個一定互吃，所以每一列剛好放一個。

一列放一個，放下去就檢查會不會被前面的皇后吃到；整列都沒地方放，就回上一列，把那個皇后往右挪。

核心觀念

八皇后問題（eight queens puzzle）是西洋棋手 Max Bezzel 在 1848 年出的謎題。把棋盤換成 n × n、放 n 個皇后，叫 n 皇后問題。

一列只放一個，所以用一個陣列就記得下整個棋盤：cols[r] 是第 r 列的皇后放在第幾行（列和行都跟陣列一樣從 0 開始數）。「同一列」從此不用檢查。

檢查新皇后（第 row 列、第 col 行）會不會被前面第 k 列的皇后吃到：同一行，cols[k] 等於 col；同一條斜線，兩格之間列差幾格、行就差幾格。兩種都沒有，才安全。

放法：place(row) 把第 row 列從最左邊試到最右邊，安全就放下、呼叫 place(row + 1)；回來之後換下一格。row 等於 n，代表每一列都放好了，算一種。 → 回溯

檢查可以更快：多用三個陣列，記每一行、每一條左斜線、每一條右斜線有沒有皇后，一格只要看三個記號。同一條右斜線上 row − col 都一樣，同一條左斜線上 row + col 都一樣。

什麼時候會用到

  • 數獨：每一格填 1 到 9，同一列、同一行、同一個九宮格不能重複。跟放皇后一樣，一格一格填，撞到了就退回去改。
  • 排課表、排考場：同一位老師同一個時段不能有兩堂課，同一間教室不能同時有兩場考試。
  • 地圖著色：相鄰的縣市要用不同的顏色，最少要幾種顏色。
  • APCS 實作題和競賽：把棋盤換成 n × n、放 n 個皇后（n 皇后問題），是回溯的標準練習題。

常見誤解

誤解：要知道斜線上有沒有皇后，得沿著斜線一格一格找

正解：不用。兩格在同一條斜線上，列差幾格、行就差幾格，一個減法就知道。

誤解：找到一組放法，這題就做完了

正解：八皇后有 92 種放法。其中很多是同一種轉個方向、翻個面，這樣算重複的話剩 12 種。

誤解：棋盤多大都放得下

正解：2 × 2 和 3 × 3 放不下：2 × 2 的任兩格都互吃，3 × 3 最多放 2 個。1 × 1 和 4 × 4 以上才有解。

誤解：遞迴回來之後，不用把皇后拿走

正解：只用 cols 的寫法，下一格會直接蓋掉 cols[row]，不用拿。用「這一行、這條斜線有沒有皇后」三個記號陣列的寫法，回來就要把記號改回去。 → 回溯

實作

C

#include <stdio.h>

#define MAX_N 12

// 第 row 列、第 col 行會不會被前面的皇后吃到；cols[k] 是第 k 列的皇后放在第幾行
int is_safe(const int cols[], int row, int col) {
    for (int k = 0; k < row; k++) {
        int diff = cols[k] - col;
        if (diff == 0 || diff == row - k || diff == k - row) {   // 同一行，或同一條斜線
            return 0;
        }
    }
    return 1;
}

// 第 0 到 row - 1 列放好了，回傳剩下的列有幾種放法
int place(int cols[], int row, int n) {
    if (row == n) {
        return 1;                   // 每一列都放好了，算一種
    }
    int ways = 0;
    for (int col = 0; col < n; col++) {
        if (is_safe(cols, row, col)) {
            cols[row] = col;        // 放下去；換下一格的時候會直接蓋掉，不用拿走
            ways += place(cols, row + 1, n);
        }
    }
    return ways;
}

// n × n 的棋盤放 n 個皇后有幾種放法（n 最大到 MAX_N）
int count_queens(int n) {
    int cols[MAX_N] = {0};
    return place(cols, 0, n);
}

int main(void) {
    printf("%d %d\n", count_queens(6), count_queens(8));
    return 0;
}

程式測試與除錯2. 4 × 4 的棋盤放 4 個皇后應該有 2 種放法，下面這段程式（n 是 4，從 place(0) 開始，最後印出 count）卻印出 24。要怎麼改？

C

void place(int row) {
    if (row == n) {
        count += 1;
        return;
    }
    for (int col = 0; col < n; col++) {
        int safe = 1;
        for (int k = 0; k < row; k++) {
            int diff = cols[k] - col;
            if (diff == 0) {
                safe = 0;
            }
        }
        if (safe == 1) {
            cols[row] = col;
            place(row + 1);
        }
    }
}
  1. 條件多加一種：diff 等於 0，或 diff 等於 row - k
  2. 條件多加兩種：diff 等於 0，或 diff 等於 row - k，或 diff 等於 k - row
  3. 把 diff 等於 0 改成 diff 不等於 0
  4. 把條件換成：diff 等於 row - k，或 diff 等於 k - row

程式效能分析3. 下面這段程式把 4 × 4 的棋盤放 4 個皇后的放法全部數完（n 是 4，從 place(0) 開始），每放下一個皇后 placed 就加 1。最後 placed 是多少？

總結

放得下，而且有 92 種放法。不用試 44 億種：一列一列放，放下去會被吃就換一格，前後只放了 2056 次皇后就全部數完。下次碰到限制很多的擺放問題，像填數獨、排課表，你就知道：一格一格放，放不下就退回去挪前一個。

課外補充

核心觀念最後提到的三個記號陣列，寫起來是這樣：一個陣列記每一行有沒有皇后，一個記每一條左斜線（編號 row + col），一個記每一條右斜線（編號 row − col + n − 1）。放下去的時候把這一格的三個記號設成 1，遞迴回來再把三個改回 0；檢查一格只要看三個記號是不是都是 0，不用跑迴圈，是 O(1)。右斜線的編號要加 n − 1，因為 row − col 可能是負的，不能直接當陣列的編號：Python 會從陣列的尾巴倒著數，C 和 C++ 會讀到陣列外面，Java 會丟出例外。n × n 的棋盤兩種斜線各有 2n − 1 條，這兩個陣列要開這麼大。
