生活應用

出門前打開電視，早安新聞的主播說今天最好要帶傘。可以不用開電視就知道要不要帶傘嗎？

複習

我們前面學了輸入與輸出，最直覺的做法是讓程式讀進今天的降雨機率，再印出來：「今天降雨機率 70%」。可是你每天還是得自己看著數字想：70% 要帶嗎？40% 呢？後來你連穿不穿外套、要不要擦防曬，都想看一眼程式就知道。可是到目前為止，我們寫的程式只會照順序一行一行從頭跑到尾，沒辦法照規則出現不同結果。

條件判斷就是要教它如何做決定。

核心觀念

條件判斷（selection）讓程式照條件走不同的路。if 後面接一個條件，也就是一個算出來是真或假的比較：rain > 50 在 rain 是 70 時成立、是 30 時不成立。成立就跑 if 底下那一塊程式（區塊，block），不成立就跳過；後面可以接 else，條件不成立時改跑 else 那一塊。到目前為止的程式只會從頭跑到尾，條件判斷是第一個讓它「分岔」的東西：同一支程式，今天印出 umbrella，明天什麼都不印。

只分「帶、不帶」有時不夠：70% 以上一定帶，50% 到 70% 之間「再看看」，50% 以下不帶。這時用 else if（Python 寫 elif）一路往下比：先看 rain >= 70，不成立才看 rain > 50，都不成立才走 else。中了一個就不再往下比，所以第二個條件不用再寫「而且小於 70」，走到它的時候 rain 一定已經小於 70 了。

條件裡面還可以再放條件，叫巢狀 if（nested if）：先判斷有沒有下雨，有下雨再判斷風大不大，風大就別撐傘、改穿雨衣。一個條件不夠用時，也可以用 &&（而且，Python 寫 and）和 ||（或者，Python 寫 or）把兩個條件接起來：rain > 50 && rain < 70 是「超過 50 而且不到 70」，兩邊都成立整個才成立；|| 是其中一邊成立就成立。

C、C++、Java 用大括號 { } 把要一起跑的那幾行框起來，縮排只是給人看的；Python 沒有大括號，縮排就是區塊：往內縮的那幾行屬於上面的 if，退回來就不屬於了。追蹤器裡三組降雨機率都挑挑看，同一支程式走的路不一樣。

什麼時候會用到

  • 手機的勿擾模式：晚上 11 點以後來電就不響，標成最愛的那幾個人打來例外。
  • 網購結帳：滿 1000 元免運，不然加 60 元運費；有輸入優惠碼再打折。
  • 遊戲：血量歸零就 Game Over，碰到金幣就加分——每一格畫面都要判斷好幾次。
  • 電腦內部：作業系統收到你按的每一個鍵，都先判斷是不是 Ctrl、是不是 Enter，再決定交給哪個程式處理；CPU 裡面每個 if 最後都變成一條「分支」指令，跳去不同的地方繼續跑。

常見誤解

誤解：else 配的是最上面那個 if

正解：else 配最近的、還沒配到 else 的那個 if（dangling else）。C、C++、Java 不看縮排，巢狀 if 要用大括號框清楚；Python 看縮排，else 跟哪個 if 對齊就配哪個。

誤解：0 < x < 10 在 C 也能判斷 x 介於 0 到 10 之間

正解：C 從左到右算：0 < x 先變成 1 或 0，再拿 1 或 0 跟 10 比，永遠成立。要寫 0 < x && x < 10。Python 可以連著寫，意思真的是「介於中間」。

誤解：C 的 if (x = 5) 是在判斷 x 等不等於 5

正解：一個等號是指定：先把 5 放進 x，再拿 5 當條件，5 不是 0 所以永遠成立。比較要寫兩個等號 x == 5。Python 和 Java 遇到這種寫法會直接報錯，反而幫你擋下來。

誤解：三個獨立的 if 跟 if／else if／else 一樣

正解：獨立的 if 每一個都會檢查，條件重疊時會中好幾個：score 是 95 時，if score >= 90、if score >= 80、if score >= 60 三個都成立，會印出三個等第。else if 中了一個就不再往下比。

誤解：C 的 if 沒加大括號，底下縮排的幾行都歸它管

正解：沒大括號只管緊接著的那一行，第二行不管條件成不成立都會跑。C、C++、Java 看的是大括號，不是縮排；兩行以上就加大括號。

實作

C

#include <stdio.h>

int main(void) {
    int score = 85;
    int late = 0;                           // 1 是遲到、0 是沒遲到

    char grade;
    if (score >= 90) {                      // 一路往下比，中了一個就不再比
        grade = 'A';
    } else if (score >= 80) {
        grade = 'B';
    } else if (score >= 60) {
        grade = 'C';
    } else {
        grade = 'D';
    }

    int ok = 0;
    if (score >= 60 && late == 0) {         // 兩個條件都成立才算
        ok = 1;
    }

    printf("%c %d\n", grade, ok);
    return 0;
}

總結

可以：讓程式讀今天的降雨機率，寫「如果超過 50% 就印出記得帶傘，不然就不印」。下次發現自己每天都在做「如果…就…」的決定，你就知道：這種判斷可以交給程式。

課外補充

switch／case：同一個變數要跟好幾個固定的值比，像選單的 1、2、3 各做一件事，C、C++、Java 可以寫 switch (choice) { case 1: … break; case 2: … break; default: … }，比一長串 else if 整齊。每個 case 結尾要寫 break，漏掉的話會一路往下掉（fall-through），把下一個 case 的程式也跑掉。幾個值要做同一件事，就把 case 疊在一起不寫 break，像下面的 1 號、2 號都是 30 元。switch 只能比「等於某個值」，score >= 90 這種範圍還是要用 if／else if。

Python 沒有 switch。3.10 以後有 match／case（APCS 程式實作的環境是 Python 3.10，可以用），寫法跟 switch 很像、結尾不用 break，幾個值做同一件事寫成 case 1 | 2；更常見的寫法是直接用 if／elif，或是把對照表放進字典（dict）用 key 查，例如 name = {1: "A", 2: "B"}[choice]。下面是飲料店的點餐機：按 1、2 號是紅茶、綠茶 30 元，3 號鮮奶茶 50 元，其他號碼沒有這個品項。C、C++、Java 用 switch，Python 用 match。

C

#include <stdio.h>

int main(void) {
    int choice = 3;              // 點餐機上按的號碼
    int price;
    switch (choice) {
        case 1:                  // 紅茶
        case 2:                  // 綠茶：跟 1 號同價，疊在一起
            price = 30;
            break;
        case 3:                  // 鮮奶茶
            price = 50;
            break;
        default:                 // 沒有這個號碼
            price = 0;
    }
    printf("%d\n", price);
    return 0;
}
