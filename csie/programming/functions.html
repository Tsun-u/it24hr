Functions　函式

生活應用

你幫飲料店寫結帳程式，點餐、結帳、印收據三個地方都要算總價，怎麼寫？

複習

我們前面學了運算式和迴圈，最直覺的做法就是把算總價那幾行，在三個地方各貼一份。老闆說：「會員打九折！」你改了三個地方。隔天又說：「學生再折 5 元！」改到第二個地方，客人拿著收據來問：「怎麼跟我付的錢不一樣？」……這時你會不會想：

要是可以把算總價那幾行取個名字，哪裡要用就叫它，要改只改一個地方就好了。

很久以前的程式設計師也這麼想過，他們把這個東西叫做函式。

核心觀念

函式（function）是一段取了名字的程式，寫一次，哪裡要用就叫它。定義的時候寫三樣東西：名字（total）、參數（parameter，要放進去的值：杯數 cups、是不是會員 member）、回傳值（return value，算完交回來的結果：總價）。C、C++、Java 每一樣都要寫型態：int total(int cups, int member) 是「放進兩個整數、交回一個整數」；什麼都不交回的函式，回傳型態寫 void。Python 寫 def total(cups, member):，不用寫型態。

呼叫（call）是寫名字加括號：total(2, 1)。這時 2 放進 cups、1 放進 member，程式跳進函式從第一行開始跑；跑到 return price，就把 price 的值交回呼叫的地方，a = total(2, 1) 的 a 拿到 90，再接著跑下一行。return 一跑，這次呼叫就結束了，函式裡寫在它後面的程式這次都不會跑。

參數是呼叫時抄過去的一份複本，叫傳值（pass by value）：函式裡改了 cups，外面放進去的那個變數不會變。陣列例外：C 傳過去的是陣列第一格的位址，C++ 寫成 vector<int>& 是同一個陣列，Java 的陣列和 Python 的 list 傳過去是同一個物件，所以函式裡改了 arr[i]，外面看得到。

在函式裡開的變數叫區域變數（local variable），只活在那一次呼叫裡：price 每次呼叫都重新開始，跑完就不見了，主程式也看不到它。寫在所有函式外面的叫全域變數（global variable），每個函式都看得到；可是誰都能改它，出錯時很難找是誰改的，所以能用參數和回傳值傳的，就不用全域變數。

每呼叫一次函式，電腦就疊上一層，記住這一層的參數和區域變數；跑完就拿掉這一層，回到下面那層呼叫它的地方。最後呼叫的最先跑完，這一疊叫呼叫堆疊（call stack），追蹤器裡一層一層疊起來的就是它。資料結構中我們也會再次提到它。 → 堆疊

什麼時候會用到

  • 外送 App 的購物車：加一份、減一份、換大杯、套優惠券，每動一下總價就重算。背後是同一個算總價的函式，每改一次就叫它一次。
  • 遊戲的扣血：被小怪打、被魔王打、踩到陷阱，都叫同一個「扣血」函式。企劃說防禦力的效果要調高，只改這個函式，每一種受傷都跟著變。
  • 前面幾頁用過的 printf、print、len，都是別人寫好的函式：你只要知道放什麼進去、會拿回什麼，不用知道裡面怎麼寫。
  • 電腦內部：程式要開檔案、讀鍵盤、在螢幕上畫一個視窗，都是呼叫作業系統提供的函式；printf 最後也是叫作業系統，把字送到螢幕上。

常見誤解

誤解：在函式裡改了參數，外面的變數也跟著變

正解：參數是呼叫時抄過去的複本，函式裡的 x = x + 1 改的是複本，外面的 x 還是原本的值。陣列例外：C 傳的是第一格的位址、C++ 的 vector<int>& 是同一個、Java 的陣列和 Python 的 list 是同一個物件，函式裡改了 arr[i]，外面看得到（實作的 fill）。

誤解：函式裡寫 print 和寫 return 一樣

正解：print 只是把值印在螢幕上，呼叫的地方拿不到；return 才把值交回去，a = total(2, 1) 的 a 才有東西。Python 的函式沒寫 return，交回來的是 None。

誤解：return 之後的程式還會跑

正解：跑到 return，這次呼叫就結束、馬上回到呼叫的地方，寫在它後面的程式這次都不會跑。實作的 is_prime 找到因數就 return 0，後面的迴圈不用再試。

誤解：區域變數下次呼叫還留著上次的值

正解：每次呼叫都是新的一層，區域變數從頭開始：追蹤器裡第二次呼叫 total，price 又是重新算的。C 的 static 區域變數例外，它會留著上一次的值。

誤解：Python 在函式裡寫 count = count + 1，就會改到全域的 count

正解：會報 UnboundLocalError：函式裡只要有指定 count，Python 就把它當成區域變數，讀它的時候它還沒有值。要改全域的，得先在函式裡寫 global count。C、C++ 的函式裡沒有同名的區域變數，用的就是全域的那個，可以直接改。

誤解：C 的函式寫在 main 後面，main 也能直接呼叫

正解：C 從上往下讀，main 呼叫還沒看到的函式，新版的編譯器直接報錯，舊版只給警告、自己猜它回傳 int，猜錯就算錯。要把函式寫在 main 前面，或在前面先宣告原型：int total(int cups, int member);。C++ 一樣；Java 的方法寫在類別裡哪裡都可以；Python 只要呼叫那一行跑到之前，def 已經跑過就好。

實作

C

#include <stdio.h>

// 回傳三個數裡最大的
int max3(int a, int b, int c) {
    int m = a;
    if (b > m) {
        m = b;
    }
    if (c > m) {
        m = c;
    }
    return m;
}

// n 是質數回傳 1，不是回傳 0
int is_prime(int n) {
    if (n < 2) {
        return 0;
    }
    int d = 2;
    while (d * d <= n) {
        if (n % d == 0) {
            return 0;                       // 找到因數就回傳，後面的迴圈不會再跑
        }
        d += 1;
    }
    return 1;
}

// 傳值：x 是呼叫時抄過來的複本，改了它，外面的 x 不會變
void add_one(int x) {
    x = x + 1;
}

// 陣列傳過來的是第一格的位址，函式裡改了，外面看得到
void fill(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        arr[i] = i * i;
    }
}

int main(void) {
    int x = 5;
    add_one(x);

    int arr[4] = {0, 0, 0, 0};
    fill(arr, 4);

    printf("%d %d %d %d %d\n", max3(3, 8, 5), is_prime(7), is_prime(9), x, arr[3]);
    return 0;
}

跑幾步

追蹤器呼叫 total 兩次：函式本體的 price = cups * 50跑 2 次，呼叫幾次就跑幾次
迴圈跑 n 次，每次呼叫一個裡面有 m 次迴圈的函式（n = 4、m = 3 時內圈跑 12 次）n·m 次，O(n·m)
實作的 is_prime(n)：d 從 2 試到 d × d 超過 n 為止最多大約 √n 次，O(√n)

呼叫函式只寫了一行，跑的卻是整個函式本體，數步數時要把它展開進去算。Big-O 的意思和怎麼算，在資料結構的附錄。 → 時間複雜度

int work(int m) {
    int c = 0;
    for (int j = 0; j < m; j++) {
        c += 1;
    }
    return c;
}

int count = 0;
for (int i = 0; i < n; i++) {
    count += work(m);
}
  1. 4
  2. 7
  3. 16
  4. 12

總結

把算總價的那段寫成一個函式、取名 total，三個地方都叫它；打九折只要改函式裡那一行。下次發現同一段程式寫了好幾次，你就知道：把它寫成函式，要用的時候叫它就好。
