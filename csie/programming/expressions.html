Expressions　運算式

生活應用

鮮奶茶 50 元，紅茶 30 元。買兩杯鮮奶茶和一杯紅茶，在程式裡面怎麼表達？

複習

我們前面學了變數，最直覺的做法就是先拿計算機算好 130，再寫 total = 130。隔天鮮奶茶漲到 55 元，你又得重算一次、改一次；老闆接著說：「今天還有 20 張訂單喔！」你按計算機按到手痠。其實，計算機背後也是程式，因此我們可以把價錢和杯數寫進程式：

把算式告訴它，再讓程式自己算，這就是運算式。

核心觀念

運算式（expression）是算得出一個值的式子，像 2 * 50 + 30；裡面的 +、* 叫運算子（operator），2、50、30 叫運算元（operand）。算術運算子有加 +、減 -、乘 *、除 /、取餘數 %。乘號寫成 *，不是 ×，也不能省略：兩杯鮮奶茶是 2 * milk。

哪個先算有規矩，叫優先順序（precedence）：括號最先，再來乘、除、取餘數，最後加、減；同一級的從左到右。所以 2 * 50 + 30 先算 2 * 50 得到 100，再加 30 得到 130，跟我們在紙上算的一樣。想要先加後乘，就加括號：(2 + 1) * 50。順序拿不準的時候，多加一對括號不會錯。

比較運算子（comparison operator）<、<=、>、>=、==、!= 算出來的不是數字，是真或假（布林值）：total >= 100 在 total 是 130 時是真，就能拿來決定「滿百送貼紙」要不要送。相等要寫兩個等號 ==；一個等號 = 是指定，把右邊的值放進左邊的變數，這兩個很容易打錯。

邏輯運算子（logical operator）把幾個真假合起來：&& 是「而且」（兩邊都真才真）、|| 是「或者」（有一邊真就真）、! 是「不是」；Python 寫成 and、or、not。它們會短路求值（short-circuit）：&& 的左邊已經是假，結果一定是假，右邊就不算了；|| 的左邊是真，右邊也不算。cups > 0 && total / cups < 60 在 cups 是 0 時，右邊的除法不會跑，就不會除以零。

位元運算（bitwise operation）把整數當成一排 0 和 1 來算，一格對一格：6 是 110、3 是 011，& 兩格都是 1 才是 1（6 & 3 是 010，也就是 2）、| 有一格是 1 就是 1（6 | 3 是 111，7）、^ 兩格不同才是 1（6 ^ 3 是 101，5）；<< 把整排往左推（1 << 3 是 1000，8，等於乘 2 三次），>> 往右推（8 >> 1 是 4）。

指定運算子（assignment operator）= 把值放進變數；+=、-=、*=、/=、%= 是「先算再放回去」的縮寫：total += tea 就是 total = total + tea，把紅茶的錢加進總價。C、C++、Java 的 i++ 是 i += 1 的再縮寫。

什麼時候會用到

  • 結帳：三樣東西的價錢加起來、付 500 元找多少，paid - total 一行就算好。
  • 時間換算：100 秒是幾分幾秒？100 / 60 是 1 分、100 % 60 是 40 秒；倒數計時、影片長度都是這樣算。
  • 判斷：血量歸零了沒（hp <= 0）、這個數是不是偶數（x % 2 == 0）、生日到了沒（month == 5 && day == 20），遊戲和程式的每個決定都先算一個真假。
  • 電腦內部：一個顏色 0xFF8800 是紅、綠、藍三個數字擠在同一個整數裡，用 >> 16 和 & 255 把紅色拆出來；檔案的讀、寫、執行權限也是用位元一格一格記的。

常見誤解

誤解：計算機按 1 + 2 × 3 會得到 9，所以程式也是 9

正解：簡易計算機是按一個算一個：1 + 2 先變成 3，再乘 3 得到 9。程式照數學的優先順序先乘後加，1 + 2 * 3 是 7；要先加再乘得寫 (1 + 2) * 3。

誤解：^ 是次方，2 ^ 3 是 8

正解：^ 是位元運算的 XOR（互斥或）：2 是 010、3 是 011，不同的位元才是 1，2 ^ 3 是 001，也就是 1。次方 Python 寫 2 ** 3；C、C++ 用 pow(2, 3)（要 #include <math.h> 或 <cmath>）、Java 用 Math.pow(2, 3)，算出來是浮點數 8.0。

誤解：= 和 == 一樣，都是等於

正解：= 是指定，把右邊的值放進左邊的變數；== 才是比較兩邊相不相等。C、C++ 裡 if (x = 5) 不會報錯：它把 5 放進 x，再把 5 當成真，條件永遠成立；Java 和 Python 會直接報錯，不讓你跑。

誤解：a / b * c 和 a / (b * c) 一樣

正解：乘和除同一級、從左到右算：a / b * c 是先算 a / b，再乘 c。12 / 3 * 2 是 8，12 / (3 * 2) 是 2。

誤解：x && y 兩邊一定都會算

正解：短路求值：&& 的左邊是假，結果一定是假，右邊就不算了；|| 的左邊是真，右邊也不算。所以 cups > 0 && total / cups < 60 在 cups 是 0 時不會除以零。Python 的 and、or 也一樣。

誤解：Python 的 not a == b 是 (not a) == b

正解：Python 的 not 比 == 低，not a == b 是 not (a == b)，也就是 a != b。C、C++、Java 剛好相反：! 比 == 高，!a == b 是 (!a) == b，要寫 !(a == b) 或 a != b。

誤解：5 > 3 印出來每種語言都是 1

正解：C、C++ 把真當成 1、假當成 0，印出 1；Python 印 True；Java 的 boolean 不能當數字用，要印 1 得寫 5 > 3 ? 1 : 0（實作裡就是這樣寫），Python 也可以用 int(5 > 3) 轉成 1。

實作

C

#include <stdio.h>

int main(void) {
    int a = 1 + 2 * 3;           // 先乘後加：7
    int b = (1 + 2) * 3;         // 括號最先：9
    int r = 7 % 3;               // 7 除以 3 的餘數：1
    int gt = 5 > 3;              // 比較的結果：C 用 1 表示真、0 表示假
    int bits_and = 6 & 3;        // 位元運算：110 和 011 一格對一格
    int bits_or = 6 | 3;
    int bits_xor = 6 ^ 3;
    int shift = 1 << 3;          // 0001 往左推三格變 1000
    printf("%d %d %d %d %d %d %d %d\n", a, b, r, gt, bits_and, bits_or, bits_xor, shift);
    return 0;
}

C++

#include <iostream>

int main() {

    int b = (1 + 2) * 3;         // 括號最先：9
    int r = 7 % 3;               // 7 除以 3 的餘數：1
    int gt = 5 > 3;              // 比較的結果：bool 放進 int，真是 1、假是 0
    int bits_and = 6 & 3;        // 位元運算：110 和 011 一格對一格
    int bits_or = 6 | 3;
    int bits_xor = 6 ^ 3;
    int shift = 1 << 3;          // 0001 往左推三格變 1000

              << bits_and << " " << bits_or << " " << bits_xor << " " << shift << "\n";

}

Java

public class Main {
    public static void main(String[] args) {
        int a = 1 + 2 * 3;           // 先乘後加：7
        int b = (1 + 2) * 3;         // 括號最先：9
        int r = 7 % 3;               // 7 除以 3 的餘數：1
        int gt = 5 > 3 ? 1 : 0;      // 比較的結果是 boolean，不能直接當數字，用 ? : 換成 1／0

        System.out.println(a + " " + b + " " + r + " " + gt + " " + bitsAnd + " " + bitsOr + " " + bitsXor + " " + shift);
    }
}

總結

兩杯鮮奶茶和一杯紅茶寫成 2 * 50 + 30：乘號是 *，程式跟我們一樣先乘後加，算出 130。下次想讓程式幫你算錢、算時間，你就知道：照數學把算式寫下來，順序拿不準就加括號。

課外補充

三元運算子 ? :：寫成 條件 ? a : b，條件成立拿 a、不成立拿 b，一行就能依條件挑一個值，例如 bigger = a > b ? a : b。C、C++、Java 都有；Python 沒有 ? :，寫成 a if a > b else b。下面的程式用它挑出 7 和 12 裡比較大的，再依 58 分挑出 pass 或 fail。

C

#include <stdio.h>

int main(void) {
    int a = 7;
    int b = 12;
    int bigger = a > b ? a : b;          // a > b 成立拿 a，不成立拿 b
    int score = 58;
    printf("%d %s\n", bigger, score >= 60 ? "pass" : "fail");
    return 0;
}

C++

#include <iostream>
#include <string>

int main() {
    int a = 7;
    int b = 12;
    int bigger = a > b ? a : b;          // a > b 成立拿 a，不成立拿 b
    int score = 58;
    std::string result = score >= 60 ? "pass" : "fail";
    std::cout << bigger << " " << result << "\n";
    return 0;
}

Java

public class Main {
    public static void main(String[] args) {
        int a = 7;
        int b = 12;
        int bigger = a > b ? a : b;      // a > b 成立拿 a，不成立拿 b
        int score = 58;
        String result = score >= 60 ? "pass" : "fail";
        System.out.println(bigger + " " + result);
    }
}

Python

a = 7
b = 12
bigger = a if a > b else b      # a > b 成立拿 a，不成立拿 b
score = 58
result = "pass" if score >= 60 else "fail"
print(bigger, result)

輸出：12 fail

整數除法碰到負數，各語言不一樣：C、C++、Java 往零的方向捨去，-7 / 2 是 -3、-7 % 2 是 -1；Python 往下取整，-7 // 2 是 -4、-7 % 2 是 1。考試的題目多半避開負數，自己寫程式時要留意。
