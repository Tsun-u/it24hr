Arrays　陣列與串列

生活應用

全班 30 個人的成績都存進程式了，我想輸入座號，就印出那個人的成績和有沒有及格，怎麼做？

複習

我們前面學了變數和判斷式，最直覺的做法就是寫 30 個變數、一串 if／else if（你輸入的座號，還要對回變數）和一個判斷式（判斷你取出來的數字有沒有及格）。在你把 else if 寫到第 15 個的時候，你收到通知：「隔壁班 35 人也麻煩你囉！」你是否已經開始懷疑人生？

陣列可以解決這個問題。

核心觀念

陣列（array）是一排同型態、連續、有編號的格子，整排共用一個名字。全班的成績不用 s1、s2、…、s30 三十個名字，一個 score 就夠：score[0] 是第一個人、score[29] 是最後一個人。方括號裡的編號叫索引（index），從 0 開始數，所以 n 格的陣列索引是 0 到 n − 1，座號 k 的成績在 score[k − 1]。

索引可以是變數，這就是它比 30 個變數強的地方：你輸入的座號本身就是位置，score[k − 1] 一行就拿到了，不用 30 個 if 一個一個對。而且不管陣列有 5 格還是 5 萬格，拿第 i 格都只要一步，O(1)。

大小：C、C++、Java 宣告時就要定幾格（int score[30]），之後不能多不能少；Python 的 list 用 append 可以一直加，所以這一頁叫「陣列與串列」。要對每一格做同一件事，用迴圈讓 i 從 0 跑到 n − 1，叫走訪（traverse）：算總和、找最高分、數幾個人不及格，都是走訪一遍。

表格用二維陣列（two-dimensional array）：table[i][j] 先列後行，table[i] 是第 i 列（第 i 個人的那一排），table[i][j] 是那一列的第 j 格（他的第 j 科）。走訪整張表就是巢狀迴圈：外圈換列、內圈換行。

陣列在記憶體裡怎麼排、為什麼拿第 i 格只要一步、插一格進中間要搬多少，資料結構中我們也會再次提到它。 → 陣列

什麼時候會用到

  • 電影院選位：一排座位存成一排格子，看 8 號位子有沒有人，直接讀編號 8 對到的那一格，不用從第一個位子一路看過去。
  • 開票：每位候選人一格，開一張票就在那位的格子加 1，開完直接讀每格是幾票，不用為每位候選人各寫一個 if。
  • 遊戲棋盤：井字遊戲、踩地雷的棋盤是二維陣列 board[列][行]，每格存這裡是空的、圈還是叉；判斷連線就是沿著列、行、斜線一格一格讀。
  • 電腦內部：下一頁的字串底下是一排字元的陣列；排序、搜尋這些演算法大多在一個陣列上一格一格走。

常見誤解

誤解：第一格是 score[1]

正解：第一格是 score[0]。索引是「離第一格幾步」，所以座號 k 的成績是 score[k − 1]：追蹤器挑 k = 3，拿到的是 score[2] = 90，不是 score[3] = 45。

誤解：n 格的陣列，最後一格是 a[n]

正解：最後一格是 a[n − 1]，a[n] 已經出界。C、C++ 不檢查，讀到的是旁邊記憶體的垃圾值、寫進去會弄壞別的變數；Java 丟 ArrayIndexOutOfBoundsException，Python 報 IndexError。Python 的 a[-1] 是倒數第一格，C、C++、Java 的 a[-1] 一樣是出界。

誤解：b = a 會把陣列複製一份

正解：Python 和 Java 的 b = a 是讓 b 和 a 指著同一排格子，改 b[0]，a[0] 也變了。要複製得明講：Python 寫 list(a) 或 a[:]，Java 寫 a.clone()。C、C++ 的陣列不能整排用 = 指定，要用迴圈一格一格抄。

誤解：宣告 int a[5] 以後，每一格都是 0

正解：Java 的 new int[5] 每格是 0；C、C++ 在函式裡宣告的 int a[5] 沒有初始值，裡面是記憶體原本的垃圾，要寫 int a[5] = {0} 才全是 0；Python 要自己寫 [0] * 5。考試的 C 題本常從這裡出。

誤解：二維陣列 a[i][j] 的 i 是行（直的）

正解：先列後行：a[i] 是第 i 列（橫的一整排），a[i][j] 是那一列裡的第 j 格。3 列 4 行的表宣告成 a[3][4]，i 最大 2、j 最大 3，兩個寫反就出界。

誤解：陣列滿了再塞下一格，它會自己變大

正解：C、C++、Java 的陣列宣告幾格就是幾格，塞第 n + 1 個就是出界；要變大得另開一個更大的陣列，把舊的搬過去。Python 的 list 要用 append 這類方法加才會長，a[5] = x 對只有 5 格的 list 一樣是 IndexError。

實作

C

#include <stdio.h>

int main(void) {
    int score[] = {72, 58, 90, 45, 88};
    int n = 5;

    int total = 0;
    for (int i = 0; i < n; i++) {           // 走訪：i 從 0 到 n - 1，每一格做同一件事
        total += score[i];
    }
    int avg = total / n;                    // 整數除法：353 / 5 = 70

    int below = 0;
    for (int i = 0; i < n; i++) {
        if (score[i] < avg) {
            below += 1;
        }
    }

    int table[3][3] = {{80, 90, 70}, {60, 75, 85}, {95, 88, 92}};   // 3 個人 × 3 科：table[i] 是第 i 個人那一列
    int rows[3] = {0, 0, 0};
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {       // 巢狀迴圈走訪二維陣列：外圈換列、內圈換行
            rows[i] += table[i][j];
        }
    }

    printf("%d %d %d %d %d\n", avg, below, rows[0], rows[1], rows[2]);
    return 0;
}

跑幾步

追蹤器的 score[k - 1]：照編號直接拿，陣列 5 格或 5 萬格都一樣1 次，O(1)
實作的走訪 total += score[i]（n = 5 時跑 5 次）n 次，O(n)
實作的二維走訪 rows[i] += table[i][j]（3 × 3 的表跑 9 次）n·m 次，O(n·m)

拿一格不管陣列多大都是一步，要每一格都看過才跟格數一起長。Big-O 的意思和怎麼算，在資料結構的附錄。 → 時間複雜度

總結

把 30 個成績放進一個陣列 score，輸入座號 k，score[k − 1] 就是那個人的成績，再用一個 if 判斷及不及格，30 個 if 變成一行。下次碰到照編號找資料，你就知道：放進陣列，用編號直接拿。

課外補充

Python 的 list 不要求每一格同型態：[1, "a", 2.5] 放得進去，所以它叫串列（list）而不叫陣列。C、C++、Java 的陣列宣告成 int 就每一格都是 int，這也是它每一格一樣大、位置算得出來的原因。

陣列交給函式時，傳過去的是它的地址，不是整個複製一份，所以函式裡改了 a[0]，外面的 a[0] 也跟著變。為什麼、還有什麼時候會改不到，在附錄「傳值與傳參考」。 → 傳值與傳參考
