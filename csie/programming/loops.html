Loops　迴圈

生活應用

喜歡的歌手發了新單曲，我想要在通勤時的半小時一直重複聽，怎麼做？

複習

我們前面學了輸出，最直覺的做法就是把「播放：新單曲」寫 10 次。寫到第 6 次時，你發現回程也要聽，還得再寫 10 次……這時你會不會想：

要是我可以改一個用來表達次數的變數，讓它自動幫我重複 n 次就好了。

恭喜，你想到的就是迴圈。

核心觀念

迴圈（loop）讓同一段程式重複執行：規則寫一次，條件成立就一直重複，不用把同樣的程式寫好幾遍。while 迴圈每一圈開頭先檢查條件：成立就把迴圈本體（body）跑一次，再回到開頭檢查；不成立就離開，接著跑迴圈後面的程式。

for 迴圈把「從幾開始、什麼時候停、每圈怎麼變」寫在同一行。C、C++、Java 的 for (int i = 1; i <= n; i++) 跟 while 寫法一模一樣：先 i = 1，每圈開頭檢查 i <= n，跑完本體做 i++。Python 的 for i in range(1, n + 1) 是讓 i 依序取 1 到 n，range 不包含結尾的那個數。

迴圈裡面再放一個迴圈，叫巢狀迴圈（nested loop）。課表就是一個：要是把整學期每一天、每一節要上什麼都列出來，會是厚厚一本冊子；課表只寫一週，每天照著上午、午休、下午跑一輪（內圈），星期一到星期五跑完是一週（外圈），學期還沒結束就再從星期一開始。外圈每跑一圈，內圈就從頭整個跑一輪。

break 是馬上離開整個迴圈；continue 是跳過這一圈剩下的部分，直接進下一圈。條件永遠成立、迴圈停不下來，叫無窮迴圈（infinite loop），最常見的原因是忘了在本體裡更新變數。

什麼時候會用到

  • 鬧鐘的貪睡：按一下就過五分鐘再響，直到你把它關掉。
  • 算全班的平均分數：從第一個人到最後一個人，一個一個加起來，再除以人數。
  • 遊戲畫面：遊戲一直重複「讀按鍵、算位置、畫一張畫面」，一秒幾十次，直到你關掉遊戲，這叫遊戲迴圈（game loop）。
  • 網站的伺服器：一直等新的連線進來，來一個處理一個，整天不停。

常見誤解

誤解：本體跑到一半條件不成立了，迴圈就會停在中間

正解：條件只在每一圈開頭檢查。本體跑到一半 i 已經超過 n，這一圈還是會跑完，回到開頭檢查才離開。

誤解：n = 0 時，迴圈至少也會跑一次

正解：while 和 for 都是先檢查再跑，n = 0 時一次都不跑，總和是 0（追蹤器挑 n = 0 看看）。C、C++、Java 的 do-while 才是先跑再檢查、至少跑一次；Python 沒有 do-while。

誤解：range(1, 5) 會跑到 5

正解：range 不包含結尾，只有 1、2、3、4。要跑到 n 要寫 range(1, n + 1)。

誤解：迴圈跑完以後，C 和 Python 的迴圈變數一樣大

正解：C 的 for (i = 1; i <= 3; i++) 跑完時 i 是 4：最後一次檢查 4 <= 3 不成立才離開。Python 的 for i in range(1, 4) 跑完時 i 停在 3。程式識讀的 C 題本和 Python 題本都會考這個差別。

誤解：continue 會回到迴圈最前面、重新開始整個迴圈

正解：continue 只跳過這一圈剩下的部分。for 迴圈會先做每圈的更新（i++）再檢查條件；while 迴圈的更新寫在本體裡，continue 跳過它的話 i 不會變，就停不下來了。

誤解：巢狀迴圈的內圈只跑一次

正解：外圈每跑一圈，內圈都從頭整個跑一輪：外圈 3 圈、內圈每次 4 圈，內圈的本體一共跑 12 次。

實作

C

#include <stdio.h>

int main(void) {
    int n = 5;

    int total = 0;
    for (int i = 1; i <= n; i++) {          // 先檢查 i <= n，成立才跑本體，跑完做 i++
        total += i;
    }

    int pairs = 0;
    for (int i = 1; i <= n; i++) {          // 巢狀迴圈：外圈每跑一圈，內圈整個跑一輪
        for (int j = i + 1; j <= n; j++) {
            pairs += 1;
        }
    }

    printf("%d %d\n", total, pairs);
    return 0;
}

跑幾步

追蹤器那段的條件 i <= n（n = 3 時檢查 4 次，最後一次不成立）n + 1 次
本體的 total += i、i += 1各 n 次
追蹤器那段整段O(n)
實作的巢狀迴圈（n = 5 時 pairs 加了 10 次）n(n − 1) / 2 次，O(n²)

數出每一行跑幾次，再看次數跟著 n 怎麼長，就是時間複雜度。Big-O 的意思和怎麼算，在資料結構的附錄。 → 時間複雜度

總結

下次把喜歡的歌設成重複播放，你就知道：那是一個迴圈，同一件事寫一次，讓它一直重複跑，不用把同一行程式寫 10 次。

課外補充

do…while 迴圈：先把本體跑一次，跑完才檢查條件，所以本體至少會跑一次，適合「先讓使用者輸入，輸入錯了再問一次」這種情況。C、C++、Java 都有：do { … } while (條件);（結尾的分號不能少）。

Python 沒有 do…while，常見的寫法是 while True: 先跑本體，最後寫 if not 條件: break，效果一樣。下面的程式讀分數，讀到不在 0～100 之間的就再讀一次：輸入 120、-5、85，讀到第三次才拿到 85。C、C++、Java 用 do…while，Python 用 while True 加 break。

C

#include <stdio.h>

int main(void) {
    int score;
    int tries = 0;
    do {                                     // 先讀一次，跑完本體才檢查條件
        scanf("%d", &score);
        tries += 1;
    } while (score < 0 || score > 100);      // 分數不合理就回去再讀；結尾的分號不能少
    printf("%d %d\n", score, tries);
    return 0;
}

C++

#include <iostream>

int main() {
    int score;
    int tries = 0;
    do {                                     // 先讀一次，跑完本體才檢查條件
        std::cin >> score;
        tries += 1;
    } while (score < 0 || score > 100);      // 分數不合理就回去再讀；結尾的分號不能少
    std::cout << score << " " << tries << "\n";
    return 0;
}

Java

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int score;
        int tries = 0;
        do {                                 // 先讀一次，跑完本體才檢查條件
            score = sc.nextInt();
            tries += 1;
        } while (score < 0 || score > 100);  // 分數不合理就回去再讀；結尾的分號不能少
        System.out.println(score + " " + tries);
    }
}

Python

tries = 0
while True:                    # 先跑本體，最後才決定要不要離開
    score = int(input())
    tries += 1
    if 0 <= score <= 100:      # do…while 的條件反過來寫：分數合理了就離開
        break
print(score, tries)
