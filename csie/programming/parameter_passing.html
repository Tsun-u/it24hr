Pass by Value & Reference　傳值與傳參考

生活應用

你把一份企劃書傳給同事修改。寄附件的話，他改完你手上這份不會變；分享雲端文件的連結，他一改你就看到了。程式把變數交給函式的時候，給的是附件，還是連結？

複習

我們在函式那頁看過：add_one(x) 在函式裡把 x 加 1，外面的 x 沒有變；可是把陣列交給函式、改它的第一格，外面的陣列卻跟著變了。同樣是交給函式，為什麼一個改不到、一個改得到？

要看函式拿到的是值的複本，還是找得到原本那一份的地址。

核心觀念

傳值（pass by value）：呼叫函式的時候，參數拿到的是抄過去的一份複本，就像寄附件。C、Java、Python 的參數都是這樣傳，C++ 沒有特別寫的時候也是。所以追蹤器裡 change 把 x 加 1，改的是函式那一層的 x，主程式那一層的 x 還是原本的值。

那陣列為什麼改得到？陣列可以很大，變數裡放的其實是它在記憶體裡的位置，叫地址（address），就像雲端文件的連結。抄過去的是這個地址，兩份地址指著同一個陣列，函式照著地址改 arr[0]，主程式看到的也是改過的那個。C 的陣列參數就是第一格的地址；Java 的陣列和物件變數存的是參考（reference），也是一個地址；Python 的變數都是指著某個物件的名字，list 傳過去，指的是同一個 list。

複本終究是複本：在函式裡把 arr 換成一個新的陣列，只是讓函式手上那份地址指到別的地方，主程式的 arr 還指著原本那個。所以記一句就夠：改「裡面」（arr[0] = 99），外面看得到；換掉「整個」（arr = 新的陣列），外面看不到。

傳參考（pass by reference）是函式直接拿到本人：C++ 的參數寫成 int &x，函式裡的 x 就是外面那個變數的另一個名字，指定新的值，外面也跟著變。四種語言裡只有 C++ 有傳參考。C 用指標（pointer）做到一樣的事：呼叫寫 increase(&x)，把 x 的地址傳過去，函式寫 void increase(int *p)，*p 就是 x 本人。Java 和 Python 沒有這兩樣，想改外面的整數，就把新的值回傳、讓外面自己接：x = increase(x)。

什麼時候會用到

  • 遊戲裡的角色升級：把角色的資料交給「升級」函式，函式要改得到那一個角色，等級和血量才會真的變；要是交過去的是複本，升級完角色還是原本的樣子。
  • 內建的排序：Python 寫 arr.sort()、Java 寫 Arrays.sort(arr)、C++ 寫 sort(arr.begin(), arr.end())，都不用接回傳值，排完你的陣列就是排好的，因為函式拿到的是你那個陣列的地址。
  • C 的 scanf("%d", &n)：scanf 要把讀到的數字放進 n，所以要給它 n 的地址 &n，它才知道放進哪裡。
  • 電腦內部：十萬筆成績交給函式，要是每呼叫一次就複製十萬格，又慢又吃記憶體；傳地址只要抄一個地址。比賽和考試的 C++ 程式常把大陣列寫成 vector<int>& 傳，就是為了不複製。

常見誤解

誤解：Java 的陣列和物件是傳參考（pass by reference）

正解：Java 一律傳值。陣列、物件變數裡放的是地址，傳過去的是地址的複本：照著地址改 arr[0]，外面看得到；在方法裡寫 arr = new int[]{0, 0}，只是讓這份複本指到新的陣列，外面的變數還指著原本那個（試試看第一題）。真的是傳參考的話，換掉參數，外面也會跟著換掉。

誤解：寫一個 swap(a, b) 函式，就能交換外面的兩個整數

正解：函式拿到的是 a、b 的複本，交換的只是複本（試試看第二題）。C 要把地址傳過去：呼叫寫 swap(&a, &b)、參數寫 int *a, int *b；C++ 的參數寫成 int &a, int &b；Java 改不到外面的 int，要把它們放進陣列或物件；Python 直接在外面寫 a, b = b, a。

誤解：Python 什麼都是物件，所以把整數交給函式，函式也改得到

正解：Python 的整數是改不了的（immutable）：x = x + 1 是算出一個新的整數，讓函式裡的 x 指過去，外面的 x 還指著原本那個。改得到的是 list、dict 這種可以改裡面的東西，而且要改裡面（arr[0] = 99、arr.append(3)），不是把 arr 換掉。

誤解：C++ 的 vector 跟 C 的陣列一樣，交給函式就改得到

正解：C++ 的參數沒寫 &，vector 會整個複製一份，函式改的是複本，外面不變，而且十萬格就要抄十萬格（實作的 replace）。要改得到、或只是不想複製，參數寫成 vector<int>& arr；只讀不改的寫 const vector<int>& arr。

誤解：C 的函式裡寫 sizeof(arr)，就能算出陣列有幾格

正解：C 的陣列交給函式，函式拿到的只是第一格的地址，sizeof(arr) 算的是地址本身的大小（常見是 8 個位元組），不是整個陣列。所以陣列要連同格數一起傳：void fill(int arr[], int n)。

誤解：scanf("%d", n) 少寫 &，只是編譯時多一個警告

正解：scanf 要知道讀到的數字放進哪裡，所以要給它地址 &n。少了 &，scanf 會把 n 裡面原本的值當成地址去寫，程式可能直接當掉，也可能悄悄寫壞別的記憶體。讀字串的 char s[100] 寫 scanf("%s", s) 不用 &，因為陣列的名字本身就是第一格的地址。

實作

C

#include <stdio.h>

// 傳值：x 是呼叫時抄過來的複本，改了它，外面的 x 不會變
void add_one(int x) {
    x = x + 1;
}

// 指標：p 存的是 x 的地址，*p 就是 x 本人，改了它外面的 x 就變了
void increase(int *p) {
    *p = *p + 1;
}

// 陣列傳過來的是第一格的地址，照著地址改裡面的格子，外面看得到
void set_first(int arr[]) {
    arr[0] = 99;
}

// arr 是地址的複本：讓它指到另一個陣列，外面的 arr 還指著原本那個
void replace(int arr[]) {
    int other[2] = {0, 0};
    arr = other;
}

int main(void) {
    int x = 5;
    add_one(x);
    printf("%d\n", x);

    increase(&x);
    printf("%d\n", x);

    int arr[2] = {1, 2};
    set_first(arr);
    replace(arr);
    printf("%d %d\n", arr[0], arr[1]);
    return 0;
}

C++

#include <iostream>
#include <vector>

// 傳值：x 是呼叫時抄過來的複本，改了它，外面的 x 不會變
void add_one(int x) {
    x = x + 1;
}

// 參考：int &x 的 x 就是外面那個變數的另一個名字，改了外面也變
void increase(int &x) {
    x = x + 1;
}

// vector<int>& 是參考：函式裡的 arr 就是外面那一個
void set_first(std::vector<int>& arr) {
    arr[0] = 99;
}

// 沒寫 &：vector 整個複製一份，函式改的是複本，外面不受影響
void replace(std::vector<int> arr) {
    arr = {0, 0};
}

int main() {
    int x = 5;
    add_one(x);
    std::cout << x << "\n";

    increase(x);
    std::cout << x << "\n";

    std::vector<int> arr = {1, 2};
    set_first(arr);
    replace(arr);
    std::cout << arr[0] << " " << arr[1] << "\n";
    return 0;
}

Java

public class Main {
    // 傳值：x 是呼叫時抄過來的複本，改了它，外面的 x 不會變
    static void addOne(int x) {
        x = x + 1;
    }

    // Java 沒有指標和參考：想改外面的整數，就把新的值回傳，讓外面自己接
    static int increase(int x) {
        return x + 1;
    }

    // 陣列傳過來的是地址的複本，照著地址改裡面的格子，外面看得到
    static void setFirst(int[] arr) {
        arr[0] = 99;
    }

    // 讓這份地址指到新的陣列，外面的 arr 還指著原本那個
    static void replace(int[] arr) {
        arr = new int[]{0, 0};
    }

    public static void main(String[] args) {
        int x = 5;
        addOne(x);
        System.out.println(x);

        x = increase(x);
        System.out.println(x);

        int[] arr = {1, 2};
        setFirst(arr);
        replace(arr);
        System.out.println(arr[0] + " " + arr[1]);
    }
}

跑幾步

交給函式一個整數 x抄 1 個值，O(1)
交給函式 n 格的 C 陣列、Java 陣列、Python list、C++ 的 vector<int>&只抄一個地址，O(1)，跟 n 多大無關
交給函式 n 格的 C++ vector<int>（沒寫 &）整個複製一份，O(n)

交給函式的東西越大，複製的代價越明顯：十萬格的 vector 沒寫 &，每呼叫一次就抄十萬格，放在迴圈裡呼叫更是倍數放大。Big-O 的意思和怎麼算，在資料結構的附錄。 → 時間複雜度

試試看

程式運行追蹤1. 下面這段程式印出什麼？

C

void reset(int arr[]) {
    arr[0] = 7;
    int other[2] = {0, 0};
    arr = other;
    arr[0] = 9;
}

int arr[2] = {1, 2};
reset(arr);
printf("%d %d\n", arr[0], arr[1]);
  1. 9 0
  2. 7 2
  3. 1 2
  4. 9 2

程式測試與除錯2. 想交換 a 和 b，跑完卻印出 3 8。問題出在哪？

C

void swap(int a, int b) {
    int tmp = a;
    a = b;
    b = tmp;
}

int a = 3;
int b = 8;
swap(a, b);
printf("%d %d\n", a, b);
  1. tmp 要先存 b，順序寫反了
  2. swap 拿到的是 a、b 的複本，交換的只是複本
  3. swap 是內建函式的名字，呼叫到的不是這一個
  4. 函式裡的 a、b 跟外面同名，名字撞在一起互相蓋掉了

程式運行追蹤3. 下面這段程式印出什麼？

C

void bump(int arr[], int n) {
    n = n + 1;
    arr[n] = arr[n] + 10;
}

int arr[3] = {1, 2, 3};
int n = 0;
bump(arr, n);
printf("%d %d %d\n", n, arr[0], arr[1]);
  1. 1 1 12
  2. 0 11 2
  3. 0 1 12
  4. 1 11 2

總結

整數這種值，交給函式時寄的是附件，函式怎麼改都不影響你；陣列、串列、物件寄的是連結，函式照著連結改，你這邊也看得到。C 想讓函式改到整數，就自己把地址寄過去（指標）；C++ 可以直接讓函式拿到本人（參考）。下次碰到函式改了東西外面卻沒變，或是不想變卻變了，你就知道：先問它拿到的是附件還是連結。

課外補充

想把陣列交給函式改，又不想動到原本那一份：先複製一份再交出去。Python 寫 f(list(arr))、Java 寫 f(arr.clone())；C++ 的參數不寫 &，vector 本來就會複製一份；C 的陣列沒有內建的複製，要自己用迴圈一格一格抄到另一個陣列。
