生活比喻

照學號尾數分的置物櫃：看尾數就知道在哪一格，尾數一樣的只好擠同一格。

什麼時候會用到

  • 用名字查電話、報手機號碼查會員點數：這種「拿一個鍵（key）去查一筆資料」的事，最常交給雜湊表，存了幾萬筆，查一次還是差不多快。
  • 寫程式最常用的「字典」：Python 的 dict、set，JavaScript 的 Map、Set，Java 的 HashMap、HashSet，C++ 的 unordered_map、unordered_set，都是雜湊表；判斷一個值出現過沒有、把重複的去掉，也是靠它。
  • 資料庫的雜湊索引、網站的快取（cache）：拿帳號、網址當鍵，直接算出資料放在哪，不用整張表掃一遍。（資料庫更常用的索引是 B 樹。） → B 樹
  • 下載頁面上那串 SHA-256：雜湊函數也能把整個檔案算成一串固定長度的「指紋」，下載完自己再算一次，對得上就代表檔案沒壞、沒被動過；Git 也是用雜湊值替每一次 commit 取名字。

核心觀念

雜湊表（hash table）底下是一個陣列，每一格叫一個桶（bucket）。放資料時，把它的鍵（key）丟進雜湊函數（hash function）算出一個數，叫雜湊值（hash value），當作格號直接放進那一格；找的時候再算一次，直接去那一格看。學號尾數就是一種雜湊函數：h(k) = k % 10。這頁的沙盒用 h(k) = k % 7，15 除以 7 餘 1，就放 1 號格。

這跟陣列頁「知道索引就直接算出位置」是同一招，只是索引從鍵算出來，所以不管存了多少筆，平均找一次都是 O(1)，不用像鏈結串列從頭一個一個走。代價是格子比可能的鍵少得多，不同的鍵難免算到同一格，這叫碰撞（collision）：22 除以 7 也餘 1，跟 15 撞在一起。好的雜湊函數會把鍵撒得很平均，但碰撞沒辦法完全避免，一定要有處理的辦法。

處理碰撞有兩大派。鏈結法（chaining）：每一格接一條鏈結串列，撞在一起的串在同一條，找的時候只要比這一條；這頁的沙盒就是這種，照放進來的順序接在後面。開放定址（open addressing）：一格只放一個，撞到了就照規則往別格找空位，最簡單的是線性探測（linear probing）——看下一格、再下一格，到最後一格就繞回 0 號格；找的時候也照同一條路線找，碰到空格才算找不到。

負載因子（load factor）α = 裝了幾個 ÷ 格數，就是表有多滿。α 越高碰撞越多，串列越長、探測越久；所以表太滿時要擴大：換一個更大的陣列，每一筆用新的格數重新算位置搬過去，叫重新雜湊（rehashing）。像 Java 的 HashMap，α 超過 0.75 就擴大成兩倍。搬一次是 O(n)，但很久才搬一次，平均下來插入還是 O(1)，跟陣列頁那個會自己長大的陣列同一個道理。

常見誤解

誤解：雜湊表找東西一定是 O(1)

正解：O(1) 是平均。最差的情況是全部撞進同一格：這頁如果放的都是 7 的倍數（7、14、21…），會全擠在 0 號格的串列裡，找一個要從頭比到尾，變成 O(n)。所以雜湊函數要把鍵撒得平均、表太滿要擴大。

誤解：雜湊表裡的東西會照放進去的順序（或照大小）排好

正解：位置是算出來的，跟先後、大小都無關：這頁依序放 15、22、30、8、10、3、17，從 0 號格讀到 6 號格是 15 22 8 30 10 3 17，兩種順序都不是。Java 的 HashMap、C++ 的 unordered_map 走訪順序沒有保證；Python 的 dict（3.7 起）、JavaScript 的 Map 會照放進去的順序，那是另外記了順序。要照大小排，用 Java 的 TreeMap、C++ 的 std::map（底下是樹）。

誤解：表的大小隨便取都一樣

正解：用除法 h(k) = k % m 時，m 最好取質數。如果鍵都是偶數、m 取 10，就只會落在 0、2、4、6、8 號格，一半的格子空著、另一半擠得更兇；m 取 7 這種質數就會撒到每一格。（Java 的 HashMap 用 2 的次方當大小，是先把雜湊值打散過再取餘數。）

誤解：k % m 算出來一定是 0 到 m − 1

正解：要看語言。Java、C++、JavaScript 的負數取餘數會是負的（-3 % 7 是 -3），拿去當格號就越界；Python 的 -3 % 7 是 4。鍵可能是負數時，要寫成 ((k % m) + m) % m，Java 也可以用 Math.floorMod(k, m)。

誤解：雜湊就是加密

正解：加密可以用金鑰解回原文；雜湊是單向的，算出來的值回推不出原本的資料（很多不同的資料還會算出同一個值）。網站存密碼存的是雜湊值，登入時把你輸入的再算一次、比對對不對得上，資料庫裡不放原本的密碼。

誤解：負載因子最多是 1，每一格都有東西就放不下了

正解：要看怎麼處理碰撞。開放定址一格只放一個，α 最多是 1；鏈結法可以一直往串列後面接，7 格放 14 個，α 就是 2，放得下，只是串列越長越慢。

誤解：開放定址刪掉一筆，把那格清空就好

正解：後面的會找不到。用線性探測放 15、22：15 放 1 號格，22 撞到就往下放 2 號格。這時把 15 刪掉、1 號格清空，再找 22，算到 1 號格看到空的，就以為沒有。所以刪除要在那格留一個「刪除過」的記號（tombstone），找的時候跳過它繼續往下找，插入時可以再拿來用。

Python：自己刻（考試要手寫）

# 自己刻：大小 7 的雜湊表，h(k) = k % 7，碰撞用鏈結法（每一格接一條串列）
SIZE = 7


class Node:
    def __init__(self, key):
        self.key = key
        self.next = None


class HashTable:
    def __init__(self):
        self.buckets = [None] * SIZE  # 每一格放那條串列的第一個節點
        self.count = 0

    def index_of(self, key):
        return key % SIZE

    def insert(self, key):
        node = Node(key)
        i = self.index_of(key)
        if self.buckets[i] is None:
            self.buckets[i] = node
        else:
            last = self.buckets[i]
            while last.next is not None:  # 碰撞：走到這一格串列的最後面接上去
                last = last.next
            last.next = node
        self.count += 1

    def find(self, key):
        node = self.buckets[self.index_of(key)]  # 算出格號直接過去，只比這一格的串列
        while node is not None:
            if node.key == key:
                return True
            node = node.next
        return False


def yes_no(found):
    return "yes" if found else "no"


table = HashTable()
for x in [15, 22, 30, 8]:
    table.insert(x)
print(yes_no(table.find(8)), yes_no(table.find(4)), table.count)

JavaScript：自己刻（考試要手寫）

// 自己刻：大小 7 的雜湊表，h(k) = k % 7，碰撞用鏈結法（每一格接一條串列）
const SIZE = 7;

class Node {
  constructor(key) {
    this.key = key;
    this.next = null;
  }
}

class HashTable {
  constructor() {
    this.buckets = new Array(SIZE).fill(null); // 每一格放那條串列的第一個節點
    this.count = 0;
  }
  indexOf(key) {
    return key % SIZE;
  }
  insert(key) {
    const node = new Node(key);
    const i = this.indexOf(key);
    if (this.buckets[i] === null) {
      this.buckets[i] = node;
    } else {
      let last = this.buckets[i];
      while (last.next !== null) last = last.next; // 碰撞：走到這一格串列的最後面接上去
      last.next = node;
    }
    this.count++;
  }
  find(key) {
    // 算出格號直接過去，只比這一格的串列
    for (let node = this.buckets[this.indexOf(key)]; node !== null; node = node.next) {
      if (node.key === key) return true;
    }
    return false;
  }
}

const yesNo = (found) => (found ? 'yes' : 'no');
const table = new HashTable();
for (const x of [15, 22, 30, 8]) table.insert(x);
console.log(yesNo(table.find(8)), yesNo(table.find(4)), table.count);

Java：自己刻（考試要手寫）

// 自己刻：大小 7 的雜湊表，h(k) = k % 7，碰撞用鏈結法（每一格接一條串列）
public class Main {
    static final int SIZE = 7;

    static class Node {
        int key;
        Node next;

        Node(int key) {
            this.key = key;
        }
    }

    static class HashTable {
        private final Node[] buckets = new Node[SIZE]; // 每一格放那條串列的第一個節點
        private int count = 0;

        int indexOf(int key) {
            return key % SIZE;
        }

        void insert(int key) {
            Node node = new Node(key);
            int i = indexOf(key);
            if (buckets[i] == null) {
                buckets[i] = node;
            } else {
                Node last = buckets[i];
                while (last.next != null) last = last.next; // 碰撞：走到這一格串列的最後面接上去
                last.next = node;
            }
            count++;
        }

        boolean find(int key) {
            // 算出格號直接過去，只比這一格的串列
            for (Node node = buckets[indexOf(key)]; node != null; node = node.next) {
                if (node.key == key) return true;
            }
            return false;
        }

        int size() {
            return count;
        }
    }

    static String yesNo(boolean found) {
        return found ? "yes" : "no";
    }

    public static void main(String[] args) {
        HashTable table = new HashTable();
        for (int x : new int[] {15, 22, 30, 8}) table.insert(x);
        System.out.println(yesNo(table.find(8)) + " " + yesNo(table.find(4)) + " " + table.size());
    }
}

C++：自己刻（考試要手寫）

// 自己刻：大小 7 的雜湊表，h(k) = k % 7，碰撞用鏈結法（每一格接一條串列）
#include <iostream>

const int SIZE = 7;

struct Node {
    int key;
    Node* next;
};

class HashTable {
    Node* buckets[SIZE] = {}; // 每一格放那條串列的第一個節點，一開始都是 nullptr
    int count = 0;

public:
    int indexOf(int key) const { return key % SIZE; }
    void insert(int key) {
        Node* node = new Node{key, nullptr};
        int i = indexOf(key);
        if (!buckets[i]) {
            buckets[i] = node;
        } else {
            Node* last = buckets[i];
            while (last->next) last = last->next; // 碰撞：走到這一格串列的最後面接上去
            last->next = node;
        }
        count++;
    }
    bool find(int key) const {
        // 算出格號直接過去，只比這一格的串列
        for (Node* node = buckets[indexOf(key)]; node; node = node->next) {
            if (node->key == key) return true;
        }
        return false;
    }
    int size() const { return count; }
};

const char* yesNo(bool found) { return found ? "yes" : "no"; }

int main() {
    HashTable table;
    for (int x : {15, 22, 30, 8}) table.insert(x);
    std::cout << yesNo(table.find(8)) << " " << yesNo(table.find(4)) << " " << table.size() << "\n";
}

輸出：yes no 4
