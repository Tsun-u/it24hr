生活比喻

排淘汰賽的對戰表：人數湊不齊就有人輪空，但每一區的左右兩半最多只差一輪，整個賽程才不會拖長。

什麼時候會用到

  • 會員名單、通訊錄這種一直有人加入，又要隨時找人、照順序列出來的資料：新會員的編號照註冊順序一直變大，一般的二元搜尋樹會歪成一條直線；AVL 每放一個就檢查，不管照什麼順序加，一百萬筆找一筆最多比 28 次。
  • 查得多、改得少的資料，像字典的單字表、郵遞區號對照表：AVL 管得比紅黑樹嚴，樹比較矮，找東西比較快；代價是插入、刪除時比較常要轉。
  • 程式語言內建的排序集合：Java 的 TreeSet、TreeMap，C++ 的 std::set、std::map，底下也是會自己平衡的二元搜尋樹，只是它們選了轉得比較少的紅黑樹。 → 紅黑樹
  • 在節點上多記一點東西、插入和旋轉時沿路更新，是很多進階結構的起點：AVL 記的是高度；多記「這棵子樹有幾個節點」，就能在 O(log n) 找出第 k 小的數、算出某個分數排第幾，像排行榜上的「你是第 1234 名」。

核心觀念

初階的樹那頁說過，二元搜尋樹不一定 O(log n)：照 10、20、30、40、50 排好的順序插進去，樹會歪成一條直線。AVL 樹（AVL tree）是會自己保持平衡的二元搜尋樹（self-balancing binary search tree），每插一個就檢查，歪了當場轉回來。名字取自 1962 年發明它的兩位蘇聯數學家 Adelson-Velsky 和 Landis，是最早的一種自平衡二元搜尋樹。 → 樹

每個節點都有一個平衡因子（balance factor）＝左子樹的高度 − 右子樹的高度。AVL 只有一條規定：每個節點的平衡因子只能是 −1、0、+1，也就是左右兩邊的高度差不超過 1。圖上每個節點下面的小數字就是它的平衡因子；高度從 0 還是 1 開始數都一樣，兩邊相減就抵掉了。

插入跟一般的二元搜尋樹一樣比下去、放在空位，再從新節點往上一個一個檢查。遇到的第一個平衡因子變成 2 或 −2 的節點就是失衡的節點（圖上的紅框），只要修好它：修完那棵子樹的高度跟插入前一樣，上面的節點就都不會失衡。

怎麼轉，看新節點落在失衡節點的哪一邊的哪一邊：LL（左邊的左邊）對它右旋一次；RR（右邊的右邊）左旋一次；LR（左邊的右邊）先對左孩子左旋、拉直成 LL，再對它右旋；RL（右邊的左邊）先對右孩子右旋、再對它左旋。旋轉（rotation）只改上下、不改左右的順序：三個節點裡大小排中間的升上來當爸爸，小的在左、大的在右，所以轉完還是二元搜尋樹，中序走訪一樣由小到大。

因為每個節點左右最多差 1，n 個節點的 AVL 樹最高大約 1.44 log₂ n 層：一百萬筆資料最多 28 層，找一個值最多比 28 次。紅黑樹的規定比較鬆，樹可能高一點，但插入、刪除時轉得比較少。 → 紅黑樹

常見誤解

誤解：失衡了就轉樹根

正解：轉的是從新節點往上遇到的第一個失衡的節點。插入 35 時，5 和樹根 50 的平衡因子都超過了（−2 和 +2），但只要轉最下面的 5，50 就跟著回到 +1。

誤解：平衡是左右兩邊的節點一樣多

正解：看的是高度差，不是節點數。左子樹是滿的三層（7 個節點）、右子樹只有兩層（2 個節點），高度差 1，還是合格的 AVL 樹。

誤解：LL 型就要左旋

正解：LL 說的是新節點落在失衡節點左邊的左邊，左邊太重，要往右轉回來，是右旋；RR 才是左旋。名字講的是新節點在哪，不是往哪邊轉。

誤解：LR 轉一次就好

正解：要轉兩次。插入 20 時直接對 50 右旋，10 升上去，左邊一層、右邊三層，還是差 2；要先對 10 左旋、拉直成 LL，再對 50 右旋。

誤解：AVL 每次插入都要轉

正解：平衡因子變成 2 或 −2 才轉。這頁七次插入只有四次要轉，另外三次放進去就是平衡的。

誤解：刪除跟插入一樣，最多修一個地方

正解：刪除可能要一路往上轉好幾次：轉完的子樹會矮一層，上面的節點可能接著失衡，最多 O(log n) 次。插入才是修好一個地方就結束。

Python：自己刻（考試要手寫）

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
        self.height = 1                  # 只有自己一個節點時高度是 1


def height(node):
    return node.height if node else 0


def update(node):
    node.height = 1 + max(height(node.left), height(node.right))


# 平衡因子：左高 − 右高
def balance(node):
    return height(node.left) - height(node.right)


# 右旋：左孩子升上來當爸爸，它原本的右子樹改接到舊的爸爸左邊
def rotate_right(z):
    y = z.left
    z.left = y.right
    y.right = z
    update(z)
    update(y)
    return y


# 左旋：右孩子升上來當爸爸，它原本的左子樹改接到舊的爸爸右邊
def rotate_left(z):
    y = z.right
    z.right = y.left
    y.left = z
    update(z)
    update(y)
    return y


# 跟二元搜尋樹一樣比下去、放在空位（一樣大的不放）；回程由下往上更新高度，失衡就轉
def insert(node, x):
    if node is None:
        return Node(x)
    if x < node.value:
        node.left = insert(node.left, x)
    elif x > node.value:
        node.right = insert(node.right, x)
    else:
        return node
    update(node)
    bf = balance(node)
    if bf > 1:                           # 左邊太重
        if x > node.left.value:          # LR：先對左孩子左旋，變成 LL
            node.left = rotate_left(node.left)
        return rotate_right(node)        # LL：右旋
    if bf < -1:                          # 右邊太重
        if x < node.right.value:         # RL：先對右孩子右旋，變成 RR
            node.right = rotate_right(node.right)
        return rotate_left(node)         # RR：左旋
    return node


# 中序：左 → 自己 → 右
def inorder(node, out):
    if node is None:
        return
    inorder(node.left, out)
    out.append(node.value)
    inorder(node.right, out)


root = None
for x in (70, 50, 5, 10, 35, 20, 65):
    root = insert(root, x)
out = []
inorder(root, out)
print(*out)

class Node {
  constructor(value) {
    this.value = value;
    this.left = null;
    this.right = null;
    this.height = 1;                    // 只有自己一個節點時高度是 1
  }
}

const height = (node) => (node ? node.height : 0);
const update = (node) => { node.height = 1 + Math.max(height(node.left), height(node.right)); };
const balance = (node) => height(node.left) - height(node.right);   // 平衡因子：左高 − 右高

// 右旋：左孩子升上來當爸爸，它原本的右子樹改接到舊的爸爸左邊
function rotateRight(z) {
  const y = z.left;
  z.left = y.right;
  y.right = z;
  update(z);
  update(y);
  return y;
}

// 左旋：右孩子升上來當爸爸，它原本的左子樹改接到舊的爸爸右邊
function rotateLeft(z) {
  const y = z.right;
  z.right = y.left;
  y.left = z;
  update(z);
  update(y);
  return y;
}

// 跟二元搜尋樹一樣比下去、放在空位（一樣大的不放）；回程由下往上更新高度，失衡就轉
function insert(node, x) {
  if (node === null) return new Node(x);
  if (x < node.value) node.left = insert(node.left, x);
  else if (x > node.value) node.right = insert(node.right, x);
  else return node;
  update(node);
  const bf = balance(node);
  if (bf > 1) {                         // 左邊太重
    if (x > node.left.value) node.left = rotateLeft(node.left);       // LR：先對左孩子左旋，變成 LL
    return rotateRight(node);           // LL：右旋
  }
  if (bf < -1) {                        // 右邊太重
    if (x < node.right.value) node.right = rotateRight(node.right);   // RL：先對右孩子右旋，變成 RR
    return rotateLeft(node);            // RR：左旋
  }
  return node;
}

// 中序：左 → 自己 → 右
function inorder(node, out) {
  if (node === null) return;
  inorder(node.left, out);
  out.push(node.value);
  inorder(node.right, out);
}

const out = [];
inorder(root, out);

Java：自己刻（考試要手寫）

import java.util.StringJoiner;

public class Main {
    static class Node {
        int value;
        int height = 1;                   // 只有自己一個節點時高度是 1
        Node left, right;

        Node(int value) {
            this.value = value;
        }
    }

    static int height(Node node) {
        return node == null ? 0 : node.height;
    }

    static void update(Node node) {
        node.height = 1 + Math.max(height(node.left), height(node.right));
    }

    // 平衡因子：左高 − 右高
    static int balance(Node node) {
        return height(node.left) - height(node.right);
    }

    // 右旋：左孩子升上來當爸爸，它原本的右子樹改接到舊的爸爸左邊
    static Node rotateRight(Node z) {
        Node y = z.left;
        z.left = y.right;
        y.right = z;
        update(z);
        update(y);
        return y;
    }

    // 左旋：右孩子升上來當爸爸，它原本的左子樹改接到舊的爸爸右邊
    static Node rotateLeft(Node z) {
        Node y = z.right;
        z.right = y.left;
        y.left = z;
        update(z);
        update(y);
        return y;
    }

    // 跟二元搜尋樹一樣比下去、放在空位（一樣大的不放）；回程由下往上更新高度，失衡就轉
    static Node insert(Node node, int x) {
        if (node == null) return new Node(x);
        if (x < node.value) node.left = insert(node.left, x);
        else if (x > node.value) node.right = insert(node.right, x);
        else return node;
        update(node);
        int bf = balance(node);
        if (bf > 1) {                                                   // 左邊太重
            if (x > node.left.value) node.left = rotateLeft(node.left);       // LR：先對左孩子左旋，變成 LL
            return rotateRight(node);                                   // LL：右旋
        }
        if (bf < -1) {                                                  // 右邊太重
            if (x < node.right.value) node.right = rotateRight(node.right);   // RL：先對右孩子右旋，變成 RR
            return rotateLeft(node);                                    // RR：左旋
        }
        return node;
    }

    // 中序：左 → 自己 → 右
    static void inorder(Node node, StringJoiner out) {
        if (node == null) return;
        inorder(node.left, out);
        out.add(String.valueOf(node.value));
        inorder(node.right, out);
    }

    public static void main(String[] args) {
        Node root = null;
        for (int x : new int[] {70, 50, 5, 10, 35, 20, 65}) root = insert(root, x);
        StringJoiner out = new StringJoiner(" ");
        inorder(root, out);
        System.out.println(out);
    }
}

C++：自己刻（考試要手寫）

#include <algorithm>
#include <iostream>
#include <vector>

struct Node {
    int value;
    int height = 1;                       // 只有自己一個節點時高度是 1
    Node* left = nullptr;
    Node* right = nullptr;
    explicit Node(int v) : value(v) {}
};

int height(const Node* node) { return node ? node->height : 0; }
void update(Node* node) { node->height = 1 + std::max(height(node->left), height(node->right)); }
int balance(const Node* node) { return height(node->left) - height(node->right); }   // 平衡因子：左高 − 右高

// 右旋：左孩子升上來當爸爸，它原本的右子樹改接到舊的爸爸左邊
Node* rotateRight(Node* z) {
    Node* y = z->left;
    z->left = y->right;
    y->right = z;
    update(z);
    update(y);
    return y;
}

// 左旋：右孩子升上來當爸爸，它原本的左子樹改接到舊的爸爸右邊
Node* rotateLeft(Node* z) {
    Node* y = z->right;
    z->right = y->left;
    y->left = z;
    update(z);
    update(y);
    return y;
}

// 跟二元搜尋樹一樣比下去、放在空位（一樣大的不放）；回程由下往上更新高度，失衡就轉
Node* insert(Node* node, int x) {
    if (!node) return new Node(x);
    if (x < node->value) node->left = insert(node->left, x);
    else if (x > node->value) node->right = insert(node->right, x);
    else return node;
    update(node);
    int bf = balance(node);
    if (bf > 1) {                                                        // 左邊太重
        if (x > node->left->value) node->left = rotateLeft(node->left);        // LR：先對左孩子左旋，變成 LL
        return rotateRight(node);                                        // LL：右旋
    }
    if (bf < -1) {                                                       // 右邊太重
        if (x < node->right->value) node->right = rotateRight(node->right);    // RL：先對右孩子右旋，變成 RR
        return rotateLeft(node);                                         // RR：左旋
    }
    return node;
}

// 中序：左 → 自己 → 右
void inorder(const Node* node, std::vector<int>& out) {
    if (!node) return;
    inorder(node->left, out);
    out.push_back(node->value);
    inorder(node->right, out);
}

// 釋放記憶體用後序：子節點先刪，最後才刪自己
void destroy(Node* node) {
    if (!node) return;
    destroy(node->left);
    destroy(node->right);
    delete node;
}

int main() {
    Node* root = nullptr;
    for (int x : {70, 50, 5, 10, 35, 20, 65}) root = insert(root, x);
    std::vector<int> out;
    inorder(root, out);
    for (size_t i = 0; i < out.size(); i++) std::cout << (i ? " " : "") << out[i];
    std::cout << "\n";
    destroy(root);
}

輸出：5 10 20 35 50 65 70

時間複雜度

search 找某個值最差也是 O(log n)
insert 插入最差也是 O(log n)
delete 刪除最差也是 O(log n)
一次旋轉O(1)
中序走訪O(n)

O(1)、O(n) 是什麼意思、怎麼算，見附錄「時間複雜度」。
