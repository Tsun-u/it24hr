Big-O　時間複雜度

生活比喻

你要幫朋友搬家，上次你自己搬家的時候，把 10 箱行李歸位花了半小時。朋友的行李有 100 箱，全部歸位的時間會是十倍嗎？

什麼時候會用到

  • 估工作量：一份名單 100 個人要處理 1 分鐘，變成一萬個人時要等 100 分鐘，還是一萬分鐘？看的就是工作量隨資料量長得多快。
  • 挑資料結構：前面每一頁最後都有一張時間複雜度表。常常要插到最前面就別用陣列，常常要照編號讀就別用鏈結串列。
  • 程式寫好之前先知道會不會太慢：資料有一百萬筆時，O(n²) 要做大約一兆步，O(n log n) 大約兩千萬步——一個要跑好幾個小時，一個眨眼就完成。
  • 考試和面試：資料結構、演算法的題目幾乎都會問「這段程式的時間複雜度是多少」。

核心觀念

Big-O 描述的是：資料量 n 變大的時候，程式的步數最多大約怎麼長。它只在乎長的速度，所以常數和比較小的項都丟掉：3n + 5 寫成 O(n)，n² + 100n 寫成 O(n²)。

常見的幾種，由快到慢：O(1) 不管資料多少都一樣（陣列讀 a[i]、堆疊 push）；O(log n) 每次砍一半（二分搜尋）；O(n) 一個一個看（線性搜尋、鏈結串列走到尾）；O(n log n) 切一半再合起來（合併排序）；O(n²) 兩兩比一遍（氣泡排序）；O(2ⁿ) 每多一個就翻倍（河內塔要搬 2ⁿ − 1 步）。

同一個操作常常分成最好、平均、最差三種情況，例如快速排序平均 O(n log n)、最差 O(n²)；雜湊表找東西平均 O(1)、最差 O(n)。沒有特別說的時候，Big-O 通常講的是最差情況。

正式定義（考試會考）：如果存在常數 c > 0 和 n₀，讓所有 n ≥ n₀ 都有 f(n) ≤ c · g(n)，就寫成 f(n) = O(g(n))，意思是 g(n) 是 f(n) 的上界。另外 Ω 是下界、Θ 是上下界都對得上，演算法小教室會細講。

同樣的方法也能估「額外用了多少記憶體」，叫空間複雜度：例如合併排序要多用 O(n) 的空間，插入排序只要 O(1)。

怎麼算

一層迴圈

total = 0
for i in range(n):
    total += a[i]

迴圈跑 n 次，每次做固定幾步，共大約 n 步：O(n)。

兩層迴圈，各跑 n 次

for i in range(n):
    for j in range(n):
        if a[i] == a[j]:
            count += 1

外層 n 次，每一次內層又跑 n 次，共 n × n = n² 步：O(n²)。

內層越跑越短

for i in range(n):
    for j in range(i + 1, n):
        compare(a[i], a[j])

內層依序跑 n − 1、n − 2、…、1 次，加起來是 n(n − 1) / 2。丟掉常數 1/2 和比較小的項，還是 O(n²)。氣泡排序、選擇排序就是這個形狀。

每次砍一半

while n > 1:
    n = n // 2

n 每圈變一半，16 → 8 → 4 → 2 → 1 砍了 4 次，剛好是 log₂ 16。要砍 log₂ n 次：O(log n)。二分搜尋就是這個形狀。

先後兩段是相加，不是相乘

for i in range(n):          # 第一段：n 步
    print(a[i])
for i in range(n):          # 第二段：n² 步
    for j in range(n):
        print(a[i], a[j])

兩段接著做，總共 n + n² 步。只留長得最快的那一項：O(n²)。巢狀才是相乘，接著做是相加。

常見誤解

誤解：O(1) 就是只做一步

正解：是「步數不會跟著資料量變」。固定做 100 步也是 O(1)。

誤解：O(n) 一定比 O(n²) 快

正解：資料少的時候不一定，前面被丟掉的常數可能差很多。Big-O 講的是 n 夠大以後，誰長得比較快。

誤解：兩層迴圈一定是 O(n²)

正解：要看內層跑幾次：內層固定跑 10 次，整段是 O(n)；內層每次砍一半，整段是 O(n log n)。

誤解：log n 的底數很重要

正解：log₂ n 和 log₁₀ n 只差一個常數倍（大約 3.3 倍），Big-O 會把常數丟掉，所以通常不寫底數。

誤解：Big-O 算的是秒數

正解：它算的是步數怎麼跟著資料量長，跟電腦快慢無關。換一台快十倍的電腦，O(n²) 的程式在資料變十倍時，還是會慢一百倍。

誤解：平均 O(1) 就代表每次都是 O(1)

正解：雜湊表平均 O(1)，最差全部撞在同一格就是 O(n)。看複雜度要看清楚講的是哪一種情況。

Sorting　排序
氣泡排序 bubble sort最好 O(n)（有提早結束）、平均 O(n²)、最差 O(n²)；額外空間 O(1)；穩定
選擇排序 selection sort最好、平均、最差都是 O(n²)；額外空間 O(1)；不穩定
插入排序 insertion sort最好 O(n)、平均 O(n²)、最差 O(n²)；額外空間 O(1)；穩定
合併排序 merge sort最好、平均、最差都是 O(n log n)；額外空間 O(n)；穩定
快速排序 quick sort最好 O(n log n)、平均 O(n log n)、最差 O(n²)；額外空間平均 O(log n)（遞迴的堆疊）；不穩定

find（內建那份：字典直接記組長）O(1)
union（內建那份：整組的組長改掉）O(n)
