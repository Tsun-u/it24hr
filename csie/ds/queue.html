生活比喻

排隊買飲料：先到的先點。

什麼時候會用到

  • 客服專線、網購出貨：照順序一個一個處理。
  • 印表機的列印工作：先送出的先印。
  • 鍵盤輸入：你打的字照順序送進程式，不會亂掉。
  • 在地圖上找最近的路（廣度優先搜尋 BFS）：一層一層往外找，靠的就是佇列。

核心觀念

佇列有兩個口：新來的從後面（rear）排進來，輪到的從前面（front）離開。

所以最先進來的會最先出去，這個特性叫 FIFO（First In, First Out，先進先出）。

你在遊戲裡為什麼是它

Queue

「你很公平。沒有人覺得你公平。」

結算卡蓋 Queue，是因為你總是照卡片進來的順序做：最早來的先處理，後來的乖乖排隊。很公平——但老闆的急件也得排在阿賢後面，所以沒有人覺得你公平。

常見誤解

誤解：佇列跟堆疊差不多

正解：堆疊是最後來的先走（LIFO），佇列是最先來的先走（FIFO）；堆疊只有頂端一個口，佇列前後各一個口。

誤解：dequeue 會把最後排進來的拿走

正解：dequeue 永遠從最前面（front）拿，拿的是最早排進來的那個。

誤解：用陣列做佇列很簡單，叫號就把第一個刪掉

正解：刪掉第一個之後，後面全部要往前挪一格，資料一多就很慢。JavaScript 的 shift()、Python 的 list.pop(0) 都是這樣；Python 請改用 collections.deque。

誤解：不挪的話，front 和 rear 一直往後走就好

正解：走到陣列尾巴就沒地方放了，前面空出來的位子卻用不到，明明有空位卻說滿了。環狀佇列（下一頁）讓它們繞回開頭，就是為了解決這件事。

Python：自己刻（考試要手寫）

class Node:
    def __init__(self, value):
        self.value = value
        self.next = None


class Queue:
    def __init__(self):
        self.front = None
        self.rear = None

    def enqueue(self, x):
        node = Node(x)
        if self.rear is None:
            self.front = self.rear = node
        else:
            self.rear.next = node
            self.rear = node

    def dequeue(self):
        if self.front is None:
            raise IndexError("queue underflow")
        x = self.front.value
        self.front = self.front.next
        if self.front is None:
            self.rear = None
        return x

    def peek(self):
        return self.front.value


q = Queue()
for x in (1, 2, 3):
    q.enqueue(x)
a = q.dequeue()
b = q.dequeue()
print(a, b, q.peek())

JavaScript：自己刻（考試要手寫）

class Queue {
  constructor() {
    this.front = null;
    this.rear = null;
  }
  enqueue(x) {
    const node = { value: x, next: null };
    if (this.rear === null) this.front = this.rear = node;
    else {
      this.rear.next = node;
      this.rear = node;
    }
  }
  dequeue() {
    if (this.front === null) throw new Error('queue underflow');
    const x = this.front.value;
    this.front = this.front.next;
    if (this.front === null) this.rear = null;
    return x;
  }
  peek() {
    return this.front.value;
  }
}

const q = new Queue();
for (const x of [1, 2, 3]) q.enqueue(x);
const a = q.dequeue();
const b = q.dequeue();
console.log(a, b, q.peek());

Java：自己刻（考試要手寫）

public class Main {
    static class Node {
        int value;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    static class Queue {
        private Node front, rear;

        void enqueue(int x) {
            Node node = new Node(x);
            if (rear == null) front = rear = node;
            else {
                rear.next = node;
                rear = node;
            }
        }

        int dequeue() {
            if (front == null) throw new IllegalStateException("queue underflow");
            int x = front.value;
            front = front.next;
            if (front == null) rear = null;
            return x;
        }

        int peek() {
            return front.value;
        }
    }

    public static void main(String[] args) {
        Queue q = new Queue();
        for (int x : new int[] {1, 2, 3}) q.enqueue(x);
        int a = q.dequeue();
        int b = q.dequeue();
        System.out.println(a + " " + b + " " + q.peek());
    }
}

C++：自己刻（考試要手寫）

#include <iostream>
#include <stdexcept>

struct Node {
    int value;
    Node* next;
};

class Queue {
    Node* front = nullptr;
    Node* rear = nullptr;

public:
    void enqueue(int x) {
        Node* node = new Node{x, nullptr};
        if (!rear) front = rear = node;
        else {
            rear->next = node;
            rear = node;
        }
    }
    int dequeue() {
        if (!front) throw std::underflow_error("queue underflow");
        Node* old = front;
        int x = old->value;
        front = front->next;
        if (!front) rear = nullptr;
        delete old;
        return x;
    }
    int peek() const { return front->value; }
};

int main() {
    Queue q;
    for (int x : {1, 2, 3}) q.enqueue(x);
    int a = q.dequeue();
    int b = q.dequeue();
    std::cout << a << " " << b << " " << q.peek() << "\n";
}

輸出：1 2 3

enqueue 排進來O(1)
dequeue 叫號O(1)
front 看下一個O(1)
找某個值在不在裡面O(n)
