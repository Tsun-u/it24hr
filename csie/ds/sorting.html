生活比喻

你幫老師把全班 30 張考卷照分數排好：每次把還沒排的那疊從頭翻到尾、抽出最高分。全年級 600 張的時候，也只能這樣一疊翻到手痠嗎？

什麼時候會用到

  • 成績排名：把全班成績由高到低排好，第幾名、前百分之幾一眼就看得出來；繁星推薦看的校排名，也是全校的成績排出來的。
  • 手機通訊錄照名字排、試算表點一下欄位就排好：不只數字，名字、日期也比得出先後，比得出先後就能排。
  • 在大量資料裡找東西：先排好，就能用附錄「搜尋」的二分搜尋，每比一次砍掉一半，一百萬筆大約比 20 次就找到；亂放的只能一筆一筆看。
  • 網購的「價格由低到高」、論壇的「最新的在最上面」：資料庫用 ORDER BY 把查到的資料排好再傳給你。資料多到記憶體放不下時，就一批一批排好存到硬碟，再像合併排序那樣把排好的幾批合併起來（外部排序，external sorting）。

核心觀念

排序（sorting）是把資料照某個順序排好：由小到大（遞增）、由大到小（遞減），或照名字、日期。這頁的五種都靠「兩個兩個比大小」決定誰在前面，叫比較排序（comparison sort）。沙盒每按一下走一輪，考試常問的「第 k 輪之後長怎樣」就是這個。

簡單的三種都在同一個陣列裡換來換去。氣泡排序（bubble sort）：從頭開始相鄰兩個比，前面比較大就交換，一輪下來最大的被推到最後，像氣泡一路浮上去。選擇排序（selection sort）：每一輪在還沒排的那段裡選出最小的，跟那段的第一個交換。插入排序（insertion sort）：像整理手上的撲克牌，把下一張插進前面已經排好的那段，比它大的往後挪一格。

這三種一輪只處理好一個數，n 個數要走 n − 1 輪、每輪最多比 n − 1 次，所以是 O(n²)：6 個數的氣泡、選擇都是 5 + 4 + 3 + 2 + 1 = 15 次。這頁的氣泡排序有「一輪都沒換就提早結束」，這組資料剛好也是第 5 輪結束，每一輪都跟沒有提早結束的課本版本一樣。

合併排序（merge sort）靠「切一半」：先把每個數當成一段，相鄰兩段合併成一段，寬度 1、2、4…一路加倍（這頁由下往上做，一輪合併一種寬度）。兩段各自排好的話，從兩段開頭比，小的先拿，比一次就放好一個。寬度每輪加倍，大約 log₂ n 輪就合成一段（6 個數 3 輪），每輪比不到 n 次，所以是 O(n log n)。合併時要一個跟原陣列一樣長的暫存陣列，放合併好的結果。

快速排序（quick sort）也靠切一半：挑一個樞紐（pivot），比它小的放左邊、大的放右邊，pivot 就落在它最後的位置，左右兩段再各自這樣切。這頁拿每段最後一個當 pivot（Lomuto 分割法），還沒切的段記在堆疊（Stack）裡；寫成遞迴時，幫你記的就是 call stack。每次都切在中間附近的話，大約 log₂ n 層、每層比不到 n 次，平均 O(n log n)。最怕的是資料已經排好、又拿最後一個當 pivot：pivot 永遠是最大的，每切一次只少一個，要切 n − 1 次，變成 O(n²)。

穩定排序（stable sort）：一樣大的資料，排完還保持原本的先後。例如考卷先照座號排好，再照分數排，穩定的排法排完，同分的仍然照座號。氣泡、插入、合併是穩定的（一樣大不交換、先拿左邊那段的）；選擇、快速不穩定，因為會跨很遠交換，可能把同分的順序對調。

原地排序（in-place sort）：只用幾個變數，直接在原陣列裡換位置，不另外開一個陣列。氣泡、選擇、插入是原地的；快速排序也算原地，只多了遞迴的堆疊（平均 O(log n)）；合併排序不是，要多 O(n) 的暫存陣列。

為什麼只靠比大小的排序最快就是 O(n log n)（下界證明）、快速排序的「平均」怎麼算出來（期望時間分析），之後的演算法小教室會講。堆積排序（heap sort）要先認識堆積（heap）這個結構，放在進階篇。

常見誤解

誤解：快速排序永遠最快

正解：最差是 O(n²)。資料已經排好、又拿最後一個當 pivot，每次只切掉 pivot 自己：[1 2 3 4 5 6] 要切 5 次、比 15 次，跟氣泡排序一樣多。實際的程式會隨機挑 pivot，或拿頭、中、尾三個數的中位數（median-of-three）來避開。

誤解：JavaScript 的 [10, 9, 1].sort() 會照數字排

正解：沒給比較函式時，會先把每個值轉成字串再比：字串 "10" 的第一個字元 "1" 比 "9" 小，所以排出 [1, 10, 9]。照數字排要寫 .sort((a, b) => a - b)。Python、Java、C++ 的數字是照數字排的，沒有這個問題。

誤解：氣泡排序沒用，只是拿來教的

正解：加上「一輪都沒換就提早結束」，資料已經排好時第 1 輪比 n − 1 次就結束，O(n)；每個數都離正確位置不遠時，也只要跑幾輪。程式又短，資料很少、幾乎排好時還是派得上用場。

誤解：穩定不穩定不重要，反正都排好了

正解：照兩個條件排就靠它：試算表先照座號排、再照分數排，第二次用穩定排序，同分的才會維持座號順序。Python 的 sorted、Java 物件陣列的 Arrays.sort、JavaScript 的 sort（ES2019 起）保證穩定；C++ 的 std::sort 不保證，要穩定得用 std::stable_sort。

誤解：選擇排序和插入排序都是 O(n²)，比的次數一樣

正解：選擇排序不管資料長怎樣，每輪都要把剩下的全部看完，6 個數固定比 15 次；插入排序遇到不比自己大的就停，這頁只比 12 次，已經排好的資料只要比 n − 1 = 5 次。反過來，選擇排序每輪最多換一次，交換的次數比較少。

誤解：合併排序第 k 輪長怎樣只有一種答案

正解：有兩種常見寫法：這頁由下往上（bottom-up），寬度 1、2、4 兩兩合併；課本也常寫成遞迴（top-down），先切成兩半、各自排好再合併。最後結果一樣，n 不是 2 的次方時中間的段卻不一樣：6 個數的遞迴版先切成 [5 2 4] 和 [6 1 3]，4 跟 6 到最後一輪才碰面；這頁第 1 輪就把 [4] [6] 合併了。寫過程前先看題目用哪一種。

Python：自己刻（考試要手寫）

# 自己刻：插入排序和快速排序各一個函式，都在原陣列上排（原地排序）


def insertion_sort(a):
    for k in range(1, len(a)):
        key = a[k]
        j = k - 1
        while j >= 0 and a[j] > key:  # 比 key 大的往後挪一格
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key


def quick_sort(a, lo, hi):
    if lo >= hi:
        return
    pivot = a[hi]  # Lomuto 分割：拿這段最後一個當 pivot
    i = lo  # 下一個比 pivot 小的要放的位置
    for j in range(lo, hi):
        if a[j] < pivot:
            a[i], a[j] = a[j], a[i]
            i += 1
    a[i], a[hi] = a[hi], a[i]  # pivot 放到 a[i]：左邊都比它小、右邊都不比它小
    quick_sort(a, lo, i - 1)
    quick_sort(a, i + 1, hi)


data = [5, 2, 4, 6, 1, 3]
a = data[:]
b = data[:]
insertion_sort(a)
quick_sort(b, 0, len(b) - 1)
if a == b:
    print(*a)
else:
    print("mismatch")

// 自己刻：插入排序和快速排序各一個函式，都在原陣列上排（原地排序）
function insertionSort(a) {
  for (let k = 1; k < a.length; k++) {
    const key = a[k];
    let j = k - 1;
    while (j >= 0 && a[j] > key) { // 比 key 大的往後挪一格
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = key;
  }
}

function quickSort(a, lo, hi) {
  if (lo >= hi) return;
  const pivot = a[hi]; // Lomuto 分割：拿這段最後一個當 pivot
  let i = lo; // 下一個比 pivot 小的要放的位置
  for (let j = lo; j < hi; j++) {
    if (a[j] < pivot) {
      [a[i], a[j]] = [a[j], a[i]];
      i++;
    }
  }
  [a[i], a[hi]] = [a[hi], a[i]]; // pivot 放到 a[i]：左邊都比它小、右邊都不比它小
  quickSort(a, lo, i - 1);
  quickSort(a, i + 1, hi);
}

const data = [5, 2, 4, 6, 1, 3];
const a = [...data];
const b = [...data];
insertionSort(a);
quickSort(b, 0, b.length - 1);
console.log(a.join(' ') === b.join(' ') ? a.join(' ') : 'mismatch');

Java：自己刻（考試要手寫）

// 自己刻：插入排序和快速排序各一個函式，都在原陣列上排（原地排序）
import java.util.Arrays;

public class Main {
    static void insertionSort(int[] a) {
        for (int k = 1; k < a.length; k++) {
            int key = a[k];
            int j = k - 1;
            while (j >= 0 && a[j] > key) { // 比 key 大的往後挪一格
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = key;
        }
    }

    static void quickSort(int[] a, int lo, int hi) {
        if (lo >= hi) return;
        int pivot = a[hi]; // Lomuto 分割：拿這段最後一個當 pivot
        int i = lo; // 下一個比 pivot 小的要放的位置
        for (int j = lo; j < hi; j++) {
            if (a[j] < pivot) {
                int t = a[i]; a[i] = a[j]; a[j] = t;
                i++;
            }
        }
        int t = a[i]; a[i] = a[hi]; a[hi] = t; // pivot 放到 a[i]：左邊都比它小、右邊都不比它小
        quickSort(a, lo, i - 1);
        quickSort(a, i + 1, hi);
    }

    public static void main(String[] args) {
        int[] data = {5, 2, 4, 6, 1, 3};
        int[] a = data.clone();
        int[] b = data.clone();
        insertionSort(a);
        quickSort(b, 0, b.length - 1);
        if (!Arrays.equals(a, b)) {
            System.out.println("mismatch");
            return;
        }
        StringBuilder out = new StringBuilder();
        for (int x : a) out.append(out.length() > 0 ? " " : "").append(x);
        System.out.println(out);
    }
}

C++：自己刻（考試要手寫）

// 自己刻：插入排序和快速排序各一個函式，都在原陣列上排（原地排序）
#include <iostream>
#include <utility>

void insertionSort(int a[], int n) {
    for (int k = 1; k < n; k++) {
        int key = a[k];
        int j = k - 1;
        while (j >= 0 && a[j] > key) { // 比 key 大的往後挪一格
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}

void quickSort(int a[], int lo, int hi) {
    if (lo >= hi) return;
    int pivot = a[hi]; // Lomuto 分割：拿這段最後一個當 pivot
    int i = lo; // 下一個比 pivot 小的要放的位置
    for (int j = lo; j < hi; j++) {
        if (a[j] < pivot) std::swap(a[i++], a[j]);
    }
    std::swap(a[i], a[hi]); // pivot 放到 a[i]：左邊都比它小、右邊都不比它小
    quickSort(a, lo, i - 1);
    quickSort(a, i + 1, hi);
}

int main() {
    const int N = 6;
    int a[N] = {5, 2, 4, 6, 1, 3};
    int b[N] = {5, 2, 4, 6, 1, 3};
    insertionSort(a, N);
    quickSort(b, 0, N - 1);
    for (int i = 0; i < N; i++) {
        if (a[i] != b[i]) {
            std::cout << "mismatch\n";
            return 0;
        }
    }
    for (int i = 0; i < N; i++) std::cout << (i ? " " : "") << a[i];
    std::cout << "\n";
}

輸出：1 2 3 4 5 6

時間複雜度

氣泡排序 bubble sort最好 O(n)（有提早結束）、平均 O(n²)、最差 O(n²)；額外空間 O(1)；穩定
選擇排序 selection sort最好、平均、最差都是 O(n²)；額外空間 O(1)；不穩定
插入排序 insertion sort最好 O(n)、平均 O(n²)、最差 O(n²)；額外空間 O(1)；穩定
合併排序 merge sort最好、平均、最差都是 O(n log n)；額外空間 O(n)；穩定
快速排序 quick sort最好 O(n log n)、平均 O(n log n)、最差 O(n²)；額外空間平均 O(log n)（遞迴的堆疊）；不穩定

O(1)、O(n) 是什麼意思、怎麼算，見附錄「時間複雜度」。

總結

600 張每次翻整疊挑最高分，要比將近 18 萬次；先分成小疊各自排好、再兩疊兩疊合起來，比 5 千次就夠。下次在試算表按下「排序」，你就知道：排法有很多種，差在要比幾次、搬幾次。
