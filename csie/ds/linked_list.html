生活比喻

尋寶遊戲：每張紙條寫著下一張藏在哪。

什麼時候會用到

  • 音樂 App 的播放清單：每首歌記著下一首是誰，臨時插一首、刪一首，只要改前後的連結，不用整份清單重排。
  • 看相簿的上一張、下一張：每張照片同時記著前一張和後一張，這就是雙向鏈結串列。
  • 堆疊、佇列的另一種做法：Queue 那頁「自己刻」的版本就是用節點串起來的，要排多少就接多少，不用先決定容量。
  • 雜湊表把撞在同一格的資料串成一條（附錄「雜湊」的鏈結法）；作業系統也用它記下哪些記憶體區塊還空著。

核心觀念

鏈結串列（linked list）由一個個節點（node）串成。每個節點放兩樣東西：資料，和指向下一個節點的指標（pointer）。第一個節點叫 head，最後一個的指標指向 null，代表到底了。

節點散落在記憶體各處，全靠指標接起來。所以插到最前面只要改兩個指標：新節點指向原本的第一個、head 改指新節點，串列再長都一樣快（O(1)）。但要找第 k 個、或走到最後一個，就得從 head 照著指標一個一個走（O(n)）。

這跟上一頁的陣列剛好相反：陣列排成一排，知道編號就能直接算出位置，插到最前面卻要整排往後搬。只能往後走的是單向鏈結串列（singly linked list）；每個節點再多記前一個是誰，就是雙向鏈結串列（doubly linked list），可以往回走。

你在遊戲裡為什麼是它

Linked List

「誰拉你，你就跟著走。」

結算卡蓋 Linked List，是因為你做卡沒有固定從哪一頭拿：不是一直挑最新的，也不是一直挑最早的，下一張做哪張，要看當下誰來拉你。鏈結串列也是這樣，下一個是誰跟擺在哪裡無關，全看指標指向誰——只是你的 next 指標，常常握在別人手上。

常見誤解

誤解：鏈結串列也能像陣列一樣，直接跳到第 k 個

正解：不行。節點散在記憶體各處，沒有編號能算出位置，只能從 head 照著指標一個一個數過去，越後面越久（O(n)）。

誤解：鏈結串列插入一定是 O(1)

正解：要「已經站在那個位置」才是。插到頭是 O(1)；要插到第 k 個，得先從 head 走過去，光走路就是 O(n)。只記 head、沒有尾指標（tail）的話，接到最後面也要走完全程。

誤解：插入時要改兩個指標，先改哪個都一樣

正解：順序反了，後面整串就不見了。把 node 插在 A 後面，要先寫 node.next = A.next，再寫 A.next = node；先改 A.next 的話，原本接在 A 後面的那一串就再也找不到了。

誤解：刪掉一個節點，只要把前一個接到下一個就好

正解：刪的是第一個時沒有「前一個」，要改的是 head；刪的是最後一個時，前一個要改成指向 null，有尾指標的話也要跟著改。這兩個邊界最常漏掉。

誤解：空的時候刪頭也沒關係

正解：head 是 null 時還去拿 head.next，Python、Java、JavaScript 會直接報錯（AttributeError、NullPointerException、TypeError），C++ 對 nullptr 取值是未定義行為，常常直接當掉。刪之前先檢查 head 是不是 null。

誤解：Python 的 list、JavaScript 的 Array 就是鏈結串列

正解：它們都是會自動變長的陣列。這兩種語言沒有內建鏈結串列，考試要自己刻；Java 有 LinkedList（雙向），C++ 有 std::list（雙向）和 std::forward_list（單向）。

Python：自己刻（考試要手寫）

class Node:
    def __init__(self, value):
        self.value = value
        self.next = None


class LinkedList:
    def __init__(self):
        self.head = None

    def insert_head(self, x):
        node = Node(x)
        node.next = self.head  # 先接上原本的第一個，再改 head；反過來後面整串會不見
        self.head = node

    def append(self, x):
        node = Node(x)
        if self.head is None:
            self.head = node
            return
        last = self.head
        while last.next is not None:  # 沒有尾指標，從頭走到最後一個
            last = last.next
        last.next = node

    def print_all(self):
        values = []
        node = self.head
        while node is not None:
            values.append(node.value)
            node = node.next
        print(*values)


nums = LinkedList()
nums.append(1)
nums.append(2)
nums.insert_head(0)
nums.print_all()

JavaScript：自己刻（考試要手寫）

class Node {
  constructor(value) {
    this.value = value;
    this.next = null;
  }
}

class LinkedList {
  constructor() {
    this.head = null;
  }
  insertHead(x) {
    const node = new Node(x);
    node.next = this.head; // 先接上原本的第一個，再改 head；反過來後面整串會不見
    this.head = node;
  }
  append(x) {
    const node = new Node(x);
    if (this.head === null) {
      this.head = node;
      return;
    }
    let last = this.head;
    while (last.next !== null) last = last.next; // 沒有尾指標，從頭走到最後一個
    last.next = node;
  }
  printAll() {
    const values = [];
    for (let node = this.head; node !== null; node = node.next) values.push(node.value);
    console.log(values.join(' '));
  }
}

const nums = new LinkedList();
nums.append(1);
nums.append(2);
nums.insertHead(0);
nums.printAll();

Java：自己刻（考試要手寫）

public class Main {
    static class Node {
        int value;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    static class LinkedList {
        private Node head;

        void insertHead(int x) {
            Node node = new Node(x);
            node.next = head;
            head = node;
        }

        void append(int x) {
            Node node = new Node(x);
            if (head == null) {
                head = node;
                return;
            }
            Node last = head;
            while (last.next != null) last = last.next;
            last.next = node;
        }

        void printAll() {
            String sep = "";
            for (Node node = head; node != null; node = node.next) {
                System.out.print(sep + node.value);
                sep = " ";
            }
            System.out.println();
        }
    }

    public static void main(String[] args) {
        LinkedList nums = new LinkedList();
        nums.append(1);
        nums.append(2);
        nums.insertHead(0);
        nums.printAll();
    }
}

C++：自己刻（考試要手寫）

#include <iostream>

struct Node {
    int value;
    Node* next;
};

class LinkedList {
    Node* head = nullptr;

public:
    void insertHead(int x) {
        Node* node = new Node{x, head}; // 先接上原本的第一個，再改 head；反過來後面整串會不見
        head = node;
    }
    void append(int x) {
        Node* node = new Node{x, nullptr};
        if (!head) {
            head = node;
            return;
        }
        Node* last = head;
        while (last->next) last = last->next; // 沒有尾指標，從頭走到最後一個
        last->next = node;
    }
    void printAll() const {
        const char* sep = "";
        for (Node* node = head; node; node = node->next) {
            std::cout << sep << node->value;
            sep = " ";
        }
        std::cout << "\n";
    }
};

int main() {
    LinkedList nums;
    nums.append(1);
    nums.append(2);
    nums.insertHead(0);
    nums.printAll();
}

輸出：0 1 2

時間複雜度

insertHead 插到頭O(1)
removeHead 刪頭O(1)
append 接到尾（只記 head）O(n)
append 接到尾（多記一個尾指標 tail）O(1)
讀第 k 個O(n)
找某個值在不在裡面O(n)

O(1)、O(n) 是什麼意思、怎麼算，見附錄「時間複雜度」。
