生活比喻

公司組織圖：最上面一個老闆，往下一層層分出去，每個人只有一個直屬主管。

什麼時候會用到

  • 運動比賽的淘汰賽賽程表：兩隊一組比，贏的往上一層，最上面是冠軍。每一場只接下面兩場的勝隊，所以它是一棵二元樹。
  • 電腦裡的資料夾：磁碟底下有資料夾，資料夾裡又有資料夾和檔案；每個檔案只會在一個資料夾裡，一層一層往下長。
  • 在大量資料裡快速找東西：二元搜尋樹每比一次就決定往左還是往右，樹夠平衡的話，一百萬筆資料大約比 20 次就找到。資料庫的索引用的是它的進化版 B 樹。 → B 樹
  • 編譯器讀算式：3 + 4 * 2 會被拆成一棵運算式樹，乘法在下層、加法在樹根。用後序走訪得到 3 4 2 * +，電腦就照這個順序算（堆疊那頁的「中序轉後序」就是這件事）。

核心觀念

樹由節點（node）和連線組成。最上面那個叫樹根（root）；往下連到的是它的子節點（child），往上連回的是父節點（parent）。除了樹根，每個節點都剛好有一個父節點，所以樹不會繞圈。沒有子節點的叫樹葉（leaf）；某個節點連同它底下的全部，叫一棵子樹（subtree）。樹根到最深的樹葉有多深，叫樹的高度（height），從 0 還是 1 開始數，各本書不同。

二元樹（binary tree）的每個節點最多只有兩個子節點，分成左子節點和右子節點，左右是有分別的。每一層都放滿的話，三層剛好 7 個節點。

二元搜尋樹（binary search tree，BST）是多了一條規則的二元樹：每個節點的左子樹都比它小、右子樹都比它大。所以找東西像查字典：從樹根開始比大小，小的往左、大的往右，一路走下去就找到；走到沒有路，就知道不在裡面。插入也是這樣比下去，走到空位就放進去。

把每個節點都拜訪一次，叫走訪（traversal）。二元樹有三種常見的走法：前序（preorder）自己 → 左 → 右、中序（inorder）左 → 自己 → 右、後序（postorder）左 → 右 → 自己。二元搜尋樹用中序走訪，剛好由小到大：左子樹都比自己小、右子樹都比自己大，「左、自己、右」就是排好的順序。

你在遊戲裡為什麼是它

Tree

「你種了一棵很漂亮的樹。」

結算卡蓋 Tree，是因為你點開了很多張卡，看了沒做，來回比較好幾張才動手。每點開一張就多長出一根樹枝，難怪這棵樹這麼漂亮：枝葉茂盛，就是還沒結果。往好處想，你把整棵樹都走訪過了；只是走訪的意思是每個節點拜訪一次，不是每個節點做完一次。

常見誤解

誤解：二元搜尋樹找東西一定是 O(log n)

正解：要看樹長得平不平衡。照 10、20、30、40、50 這種排好的順序插進去，每個都比前一個大、一路往右，樹會長成一條直線（歪斜樹），跟鏈結串列一樣得一個一個比，變成 O(n)。會自己保持平衡的 AVL 樹、紅黑樹，進階篇會講。

誤解：二元樹就是二元搜尋樹

正解：二元樹只規定每個節點最多兩個子節點，沒管大小；「左小右大」是二元搜尋樹另外加的規則。堆積（Heap）也是二元樹，規則又不一樣：父節點一定比子節點大（或小），所以最大（或最小）的永遠在樹根；堆積排序（heap sort）就是靠它，放在進階篇。

誤解：中序走訪出來一定是排好的

正解：只有二元搜尋樹才是。一般的二元樹沒有左小右大的規則，中序走出來就只是其中一種順序。

誤解：前序、中序、後序的前中後，說的是先走左邊還是右邊

正解：三種都是先左後右。前中後說的是「自己」排在哪：自己在最前面是前序、夾在中間是中序、排最後是後序。

誤解：樹的高度一定從 1 開始算

正解：各本教科書不同：有的數層數，只有樹根的樹高度是 1（例如 Horowitz 的資料結構課本）；有的數連線，同一棵樹高度是 0（例如 CLRS《演算法導論》）。滿的二元樹節點數公式也跟著變，2ʰ − 1 或 2ʰ⁺¹ − 1，考試前先看清楚題目怎麼定義。

Python：自己刻（考試要手寫）

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


# 走到空位就放新節點；比自己小往左、比自己大往右，一樣大的不放
def insert(node, x):
    if node is None:
        return Node(x)
    if x < node.value:
        node.left = insert(node.left, x)
    elif x > node.value:
        node.right = insert(node.right, x)
    return node


# 中序：左 → 自己 → 右
def inorder(node, out):
    if node is None:
        return
    inorder(node.left, out)
    out.append(node.value)
    inorder(node.right, out)


root = None
for x in (50, 30, 70, 20, 40):
    root = insert(root, x)
out = []
inorder(root, out)
print(*out)

Java：自己刻（考試要手寫）

import java.util.StringJoiner;

public class Main {
    static class Node {
        int value;
        Node left, right;

        Node(int value) {
            this.value = value;
        }
    }

    // 走到空位就放新節點；比自己小往左、比自己大往右，一樣大的不放
    static Node insert(Node node, int x) {
        if (node == null) return new Node(x);
        if (x < node.value) node.left = insert(node.left, x);
        else if (x > node.value) node.right = insert(node.right, x);
        return node;
    }

    // 中序：左 → 自己 → 右
    static void inorder(Node node, StringJoiner out) {
        if (node == null) return;
        inorder(node.left, out);
        out.add(String.valueOf(node.value));
        inorder(node.right, out);
    }

    public static void main(String[] args) {
        Node root = null;
        for (int x : new int[] {50, 30, 70, 20, 40}) root = insert(root, x);
        StringJoiner out = new StringJoiner(" ");
        inorder(root, out);
        System.out.println(out);
    }
}

C++：自己刻（考試要手寫）

#include <iostream>
#include <vector>

struct Node {
    int value;
    Node* left = nullptr;
    Node* right = nullptr;
    explicit Node(int v) : value(v) {}
};

// 走到空位就放新節點；比自己小往左、比自己大往右，一樣大的不放
Node* insert(Node* node, int x) {
    if (!node) return new Node(x);
    if (x < node->value) node->left = insert(node->left, x);
    else if (x > node->value) node->right = insert(node->right, x);
    return node;
}

// 中序：左 → 自己 → 右
void inorder(const Node* node, std::vector<int>& out) {
    if (!node) return;
    inorder(node->left, out);
    out.push_back(node->value);
    inorder(node->right, out);
}

// 釋放記憶體用後序：子節點先刪，最後才刪自己
void destroy(Node* node) {
    if (!node) return;
    destroy(node->left);
    destroy(node->right);
    delete node;
}

int main() {
    Node* root = nullptr;
    for (int x : {50, 30, 70, 20, 40}) root = insert(root, x);
    std::vector<int> out;
    inorder(root, out);
    for (size_t i = 0; i < out.size(); i++) std::cout << (i ? " " : "") << out[i];
    std::cout << "\n";
    destroy(root);
}

輸出：20 30 40 50 70

時間複雜度

insert 插入平均 O(log n)、最差 O(n)
search 找某個值平均 O(log n)、最差 O(n)
前序／中序／後序走訪O(n)

O(1)、O(n) 是什麼意思、怎麼算，見附錄「時間複雜度」。
