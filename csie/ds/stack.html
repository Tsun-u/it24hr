Stack　堆疊

生活比喻

一疊盤子：最後放上去的，最先被拿走。

什麼時候會用到

  • 文書軟體的復原（Ctrl+Z）：每做一個動作疊一筆，復原從最新的那筆開始退。
  • 瀏覽器的「上一頁」：每開一頁就疊上去，按上一頁就把最上面那頁拿掉。
  • 檢查括號有沒有配對、把算式從中序轉成後序：編譯器和計算機都靠它。
  • 程式呼叫函式：呼叫時疊上一層，做完就拿掉、回到上一層。程式當掉時印出的那一長串就是它（call stack）。

核心觀念

堆疊只有一個出入口，叫頂端（top）。東西只能從頂端放進去，也只能從頂端拿出來。

所以最後放進去的會最先出來，這個特性叫 LIFO（Last In, First Out，後進先出）。

河內塔是最經典的堆疊模型：三根柱子各是一個堆疊，每次只能搬最上面那片，大的不能壓在小的上面。

你在遊戲裡為什麼是它

Stack

「永遠做最新進來的。早上第一件事：未開啟。」

結算卡蓋 Stack，是因為你總是先做最新進來的卡：看板一來新卡你就去做它，早上那張一直壓在最底下。跟盤子一樣，最早放的最晚被拿到。

常見誤解

誤解：pop 會把最下面那個拿出來

正解：pop 永遠拿最上面、也就是最後放進去的那個。

誤解：peek 跟 pop 一樣

正解：peek 只是看一眼最上面是誰，東西還留在堆疊裡；pop 才會真的拿走。

誤解：依序放進 1、2、3，拿出來一定是 3、2、1

正解：不一定。可以邊放邊拿：放 1、拿 1、放 2、放 3、拿 3、拿 2，拿出來是 1、3、2。但不管怎麼穿插，都不可能拿出 3、1、2。

誤解：堆疊就是陣列

正解：陣列只是其中一種做法，用鏈結串列也能做。堆疊說的是「只能從頂端進出」這個規則，不是東西怎麼存。

誤解：空的時候再拿也沒關係

正解：這叫 underflow。Python、Java 會直接報錯，C++ 的 std::stack 不檢查（結果無法預期），JavaScript 的陣列則默默回傳 undefined，更難發現。拿之前要先檢查是不是空的。

誤解：河內塔多一片，只是多搬幾步

正解：每多一片，步數會翻倍再加一：3 片 7 步、4 片 15 步、10 片就要 1023 步（2ⁿ − 1）。

Python：自己刻（考試要手寫）

class Stack:
    def __init__(self, capacity):
        self.items = [None] * capacity
        self.top = -1

    def push(self, x):
        if self.top + 1 == len(self.items):
            raise OverflowError("stack overflow")
        self.top += 1
        self.items[self.top] = x

    def pop(self):
        if self.top == -1:
            raise IndexError("stack underflow")
        x = self.items[self.top]
        self.top -= 1
        return x

    def peek(self):
        return self.items[self.top]


s = Stack(6)
for x in (1, 2, 3):
    s.push(x)
a = s.pop()
b = s.pop()
print(a, b, s.peek())

JavaScript：自己刻（考試要手寫）

class Stack {
  constructor(capacity) {
    this.items = new Array(capacity);
    this.top = -1;
  }
  push(x) {
    if (this.top + 1 === this.items.length) throw new Error('stack overflow');
    this.items[++this.top] = x;
  }
  pop() {
    if (this.top === -1) throw new Error('stack underflow');
    return this.items[this.top--];
  }
  peek() {
    return this.items[this.top];
  }
}

const s = new Stack(6);
for (const x of [1, 2, 3]) s.push(x);
const a = s.pop();
const b = s.pop();
console.log(a, b, s.peek());

Java：自己刻（考試要手寫）

public class Main {
    static class Stack {
        private final int[] items;
        private int top = -1;

        Stack(int capacity) {
            items = new int[capacity];
        }

        void push(int x) {
            if (top + 1 == items.length) throw new IllegalStateException("stack overflow");
            items[++top] = x;
        }

        int pop() {
            if (top == -1) throw new IllegalStateException("stack underflow");
            return items[top--];
        }

        int peek() {
            return items[top];
        }
    }

    public static void main(String[] args) {
        Stack s = new Stack(6);
        for (int x : new int[] {1, 2, 3}) s.push(x);
        int a = s.pop();
        int b = s.pop();
        System.out.println(a + " " + b + " " + s.peek());
    }
}

C++：自己刻（考試要手寫）

#include <iostream>
#include <stdexcept>

class Stack {
    int items[6];
    int top = -1;

public:
    void push(int x) {
        if (top + 1 == 6) throw std::overflow_error("stack overflow");
        items[++top] = x;
    }
    int pop() {
        if (top == -1) throw std::underflow_error("stack underflow");
        return items[top--];
    }
    int peek() const { return items[top]; }
};

int main() {
    Stack s;
    for (int x : {1, 2, 3}) s.push(x);
    int a = s.pop();
    int b = s.pop();
    std::cout << a << " " << b << " " << s.peek() << "\n";
}

輸出：3 2 1

時間複雜度

push 放進O(1)
pop 拿出O(1)
peek 看頂端O(1)
找某個值在不在裡面O(n)
